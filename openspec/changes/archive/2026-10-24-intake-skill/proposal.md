# Proposal

## Why

Инструменты разбора листа построены (`problem-intake`), страница
разговора — тоже (`assistant-chat`): Администратор прикладывает к реплике
снимок листа, и Помощник получает строку «Загружен черновик сборки N
«имя», страниц: K.». Но порядка действий у Помощника нет: общие правила
`agent/CLAUDE.md` писались до Черновика Задачи и ещё велят «заводит
значения словаря Администратор на своей странице», хотя `create_method`
уже есть. Без навыка Помощник делает то же, но хуже и с лишними
вопросами; испортить ничего не может — это держат инструменты
(ADR-0057, «навык — вежливость, инструмент — замок»). Элемент бэклога
`intake-skill`, верхний доступный; после него горизонт редакции 3
становится проверяемым сеансом учителя.

Разведка нашла то, чего карточка не знала: Реплика идёт в клетке
`--tools ""` (`TurnRunner.java:191-195`), а навыки `.claude/skills/`
Claude Code подгружает встроенным инструментом `Skill`, которого в клетке
нет. Проверено на Claude Code 2.1.310: при `--tools ""` список
инструментов процесса пуст, навык из `.claude/skills/` модель не видит,
а тот же файл, импортированный из `CLAUDE.md` строкой
`@.claude/skills/<имя>/SKILL.md`, до модели доходит. Навык, положенный
только по пути из карточки, был бы мёртвым — тихо.

## What Changes

- **Навык разбора листа** `agent/.claude/skills/problem-intake/SKILL.md`:
  когда срабатывает (лист, снимок, страницы сборника, строка «Загружен
  черновик сборки»); откуда исходники — из этой строки или по
  `list_assembly_drafts`; обзор не больше четырёх страниц за реплику,
  сборник — по диапазону, который назвал учитель; по каждой задаче —
  куски по Рамкам в порядке чтения, текст Markdown с формулами LaTeX,
  сомнительное пометкой `⟦…⟧` с причиной, Темы из листьев, Методы
  и Характеристики из словарей, новые Методы — отдельным списком;
  `create_problem_draft` на каждую, затем по одной — ссылка на вычитку
  и ожидание «ок»; перед правкой — `get_problem_draft`, правка —
  `update_problem_draft` с версией прочитанного, «добавь» значит добавь
  к прочитанному; отказ инструмента — перечитать и сказать учителю,
  не повторять вслепую; `save_problem_draft` по «ок»; новый Метод —
  `create_method` только после «да». Независимые вызовы — одним ходом:
  у Реплики десять ходов и 180 секунд.
- **`agent/CLAUDE.md`**: импорт навыка строкой `@…/SKILL.md` — так навык
  доходит до Помощника в клетке; правило словаря исправлено — Метод
  заводится `create_method` после согласия учителя, Характеристика
  по-прежнему только Администратором на странице словарей; черновики
  Задачи названы среди того, чем действует Помощник.
- **Сторож подгрузки**: каждый `agent/.claude/skills/*/SKILL.md`
  импортирован из `agent/CLAUDE.md`, и каждый импорт ведёт к существующему
  файлу — иначе сборка падает. Навык `backfill-skill` попадёт под того же
  сторожа.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `assistant-turns`: новое требование «Навык рабочего места доходит
  до Помощника в клетке» — навык подгружается импортом из общих правил,
  а не встроенным инструментом, которого в клетке нет; не импортированный
  навык и импорт несуществующего файла роняют сборку. Порядок действий
  навыка требованием не становится (ADR-0023, ADR-0057): его признак
  готовности — сеанс учителя.

## Версия

`MINOR` — есть дельта спек (standards.md, «Версии»): 3.7.0 → 3.8.0.
`MAJOR` не предлагается: новой возможности навык не даёт — всё, что
Помощник делает по нему, умели инструменты `problem-intake`, навык лишь
упорядочивает (след решения — design.md, Р7). Строка журнала:
«`intake-skill` — навык Помощника для разбора листа: распознать пачкой,
подтвердить по одной, перечитать перед правкой, Метод завести только
после «да»; навык подгружается импортом из общих правил, что сторожит
тест».

## Impact

- Решения: новых записей журнала нет. Изменение исполняет ADR-0057
  (навык — документ в `agent/`, признак готовности — сеанс учителя)
  и ADR-0056 (инструменты — тонкие обёртки; навык прав не добавляет).
  Способ подгрузки — импорт вместо инструмента `Skill` — решён
  в design.md (Р1): клетка ADR-0057 не расширяется.
- Файлы: `agent/CLAUDE.md`, новый
  `agent/.claude/skills/problem-intake/SKILL.md`, сторож в
  `AgentSkillsNameRegisteredToolsTest`. Java-кода приложения изменение
  не трогает; команда процесса и клетка прежние.
- Граница общего и личного: не затрагивает — текст навыка; всё, что
  защищает данные (личные Черновики, права Администратора, версия),
  держат инструменты и сервисы `locus-mcp` и `problem-intake`.
- Признак готовности — сеанс учителя по карточке: лист с тремя задачами →
  три Черновика Задачи → три Задачи, с одной правкой Рамки на странице
  и одним «добавь» в чате; ни одного Метода без «да»; сторожа зелёные.
  Сеанс проводит владелец после выкладки; сборка его не заменяет.
