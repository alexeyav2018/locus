## ADDED Requirements

### Requirement: Поиск по номерам Задач — прямой выбор

Система SHALL принимать на экране поиска список номеров Задач отдельной
формой «Номера Задач» со своей кнопкой, над условиями разметки. Заданные
номера SHALL отменять все условия разметки: результат — ровно Задачи
с этими номерами, а условия разметки, пришедшие в том же адресе,
MUST NOT влиять на результат
([ADR-0064](../../context/adr/0064-nomera-zadach-pryamoj-vybor-v-poiske.md)).
Каждая форма SHALL отправлять только свои поля, а на странице результата
SHALL быть заполнена та форма, которой искали.

Номера SHALL разделяться запятыми, пробелами, точками с запятой
и переводами строк в любой смеси; повторённый номер — один номер.
Кусок, не являющийся номером (в том числе диапазон «3-7»), SHALL давать
отказ, называющий этот кусок, без результата. Пустое поле SHALL давать
отказ «Не задано ни одного номера», а не всю библиотеку.

Номер, которого нет в библиотеке, MUST NOT отменять найденных: найденные
SHALL показываться, а ненайденные SHALL называться строкой «Нет
в библиотеке: …».

Результат по номерам показывается так же, как результат по разметке:
номер, Часть, разметка, пометка «без текста», число найденных, отметки
для выдачи и Разминки.

#### Scenario: Номера в любой смеси разделителей

- **WHEN** в библиотеке есть Задачи № 3, 7 и 12 и учитель ищет
  по номерам «12, 3;7»
- **THEN** показываются Задачи № 12, 7 и 3 в этом порядке
- **AND** форма номеров заполнена введённым текстом, форма разметки пуста

#### Scenario: Номера отменяют условия разметки

- **WHEN** в адресе заданы номера 3, 7, 12 и узел рубрикатора, под которым
  лежит только Задача № 3
- **THEN** показываются Задачи № 12, 7 и 3

#### Scenario: Номера нет в библиотеке

- **WHEN** учитель ищет по номерам «3, 999», а Задачи № 999 нет
- **THEN** показывается Задача № 3
- **AND** строка «Нет в библиотеке: 999» называет пропавший номер

#### Scenario: Посторонний кусок

- **WHEN** учитель ищет по номерам «3, пять»
- **THEN** результата нет
- **AND** отказ называет «пять»

#### Scenario: Повторённый номер

- **WHEN** учитель ищет по номерам «3 3 3»
- **THEN** Задача № 3 показывается один раз

#### Scenario: Пустое поле номеров

- **WHEN** учитель отправляет форму номеров с пустым полем
- **THEN** результата нет
- **AND** отказ сообщает, что не задано ни одного номера

## MODIFIED Requirements

### Requirement: Поиск отбирает Задачи по четырём условиям

Система SHALL отбирать Задачи общей библиотеки по четырём условиям:

| Условие | Значений | Что отбирает |
| --- | --- | --- |
| Узел рубрикатора | не более одного | Задачи, размеченные Темами поддерева этого узла |
| Метод | любое число | Задачи, размеченные выбранными Методами |
| Характеристика | любое число | Задачи, размеченные выбранными Характеристиками |
| Часть | не более одной | Задачи этой Части |

Каждое условие необязательно. Заданные условия соединяются по «и»: Задача
попадает в результат, только если удовлетворяет всем заданным сразу.
Переключателя у соединения **разных** условий нет: они отвечают за разные
измерения разметки. Заданные номера Задач отменяют все четыре условия —
см. требование «Поиск по номерам Задач — прямой выбор».

Узел и Часть берут не более одного значения
([ADR-0064](../../context/adr/0064-nomera-zadach-pryamoj-vybor-v-poiske.md)):
множество Тем поддерева вычисляет система, а не набирает учитель, а у Задачи
ровно одна Часть.

#### Scenario: Условия соединяются по «и»

- **WHEN** заданы Метод и Часть
- **THEN** возвращаются только Задачи, размеченные этим Методом **и**
  относящиеся к этой Части
- **AND** Задача, у которой совпало лишь одно из двух, не возвращается

#### Scenario: Одно условие

- **WHEN** задана только Характеристика
- **THEN** возвращаются все Задачи библиотеки, размеченные этой
  Характеристикой, независимо от их Тем, Методов и Части

#### Scenario: Условий не задано

- **WHEN** поиск запускается без единого условия
- **THEN** возвращаются все Задачи библиотеки

#### Scenario: Ничего не найдено

- **WHEN** условиям не удовлетворяет ни одна Задача
- **THEN** результат пуст
- **AND** сообщается, что по этим условиям Задач нет

### Requirement: Результат поиска показывает Задачи номером и разметкой, полностью

Система SHALL показывать каждую найденную Задачу её номером,
Частью, Темами, Методами и Характеристиками, и SHALL давать перейти
от строки результата к самой Задаче. Порядок — по убыванию номера, при поиске
по разметке и по номерам одинаково.

Система SHALL показывать число найденных Задач и SHALL возвращать все
найденные Задачи. Молчаливое усечение выдачи MUST NOT применяться: учитель
не отличает «больше нет» от «показано не всё», и решает он при этом, чего
в библиотеке не хватает
([ADR-0064](../../context/adr/0064-nomera-zadach-pryamoj-vybor-v-poiske.md)).

Строка Задачи без текста SHALL нести пометку «без текста», а результат
SHALL называть, у скольких из найденных Задач текста нет. «Без текста»
показывается честно и ничем не маскируется
([ADR-0055](../../context/adr/0055-tekst-zadachi-pervichen-pdf-otrisovka.md)):
от доли Задач с текстом зависит, что учитель может с найденным сделать
дальше.

Разметка показывается именами, а не идентификаторами, а Темы — полными
путями от корня: одинаковые имена под разными родителями законны, и в списке
результатов они были бы неразличимы.

Заданные условия SHALL оставаться видимыми вместе с результатом — выбранные
значения выбранными, выбранные способы соединения отмеченными. Иначе,
увидев тридцать строк, учитель не знает, каким прочтением он их получил.

#### Scenario: Строка результата

- **WHEN** Задача попала в результат
- **THEN** видны её номер, Часть, Темы, Методы и Характеристики
- **AND** из строки можно открыть саму Задачу

#### Scenario: Размер результата назван

- **WHEN** поиск вернул Задачи
- **THEN** показывается, сколько их найдено
- **AND** показаны все найденные, без усечения

#### Scenario: Число Задач без текста названо

- **WHEN** поиск вернул пять Задач, две из которых без текста
- **THEN** результат называет, что без текста — две
- **AND** строки этих двух Задач помечены «без текста»

#### Scenario: Все найденные с текстом

- **WHEN** у всех найденных Задач есть текст
- **THEN** результат называет, что без текста — ни одной
- **AND** ни одна строка не помечена «без текста»

#### Scenario: Порядок результата

- **WHEN** поиск по разметке вернул Задачи № 3, 7 и 12
- **THEN** они идут в порядке 12, 7, 3

#### Scenario: Условия видны вместе с результатом

- **WHEN** поиск выполнен с двумя выбранными Методами и способом «все сразу»
- **THEN** вместе с результатом видно, что выбраны именно эти Методы
- **AND** видно, что выбран способ «все сразу»
