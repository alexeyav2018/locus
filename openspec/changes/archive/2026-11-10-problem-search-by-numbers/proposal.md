# Proposal

## Why

Отзыв владельца 09.11.2026: у учителя часто уже есть список номеров
Задач — «3, 5, 7, 12» с бумаги, из прошлого варианта, — а экран поиска
`/problems` отбирает только по разметке (`ProblemFilter.java:43-48`:
узел, Методы, Характеристики, Часть). Собрать эти Задачи для выдачи
или Разминки можно, лишь листая библиотеку или открывая каждую по номеру.
Номер — единственное, чем Задача названа человеку
([ADR-0050](../../context/adr/0050-zadacha-razlichaetsya-tolko-nomerom.md)).

Решения по поведению приняты владельцем вопросами 09.11.2026 (карточка
бэклога). Номера отменяют прочие условия, а не соединяются с ними по «и»,
— это отступление от [ADR-0031](../../context/adr/0031-uslovija-poiska-po-biblioteke.md);
новая запись [ADR-0064](../../context/adr/0064-nomera-zadach-pryamoj-vybor-v-poiske.md)
(«Предложено») его заменяет, повторяя остающееся в силе.

Элемент бэклога `problem-search-by-numbers`, верхний доступный.

## What Changes

- **Своя форма номеров на экране поиска.** Блок «Номера Задач» над «Где
  искать» в левой колонке: поле и своя кнопка «Поиск». Форма отправляет
  только `numbers` (и `from`, если он есть); форма разметки — только свои
  поля. На странице результата заполнена та форма, которой искали.
- **Прямой выбор.** `?numbers=` с непустым текстом показывает ровно
  Задачи с этими номерами; условия разметки в том же адресе
  не действуют. Пустое поле номеров — отказ «Не задано ни одного номера».
- **Формат поля.** Разделители — запятые, пробелы, точки с запятой,
  переводы строк в любой смеси; повтор — один номер; диапазонов нет;
  посторонний кусок (`пять`, `3-7`) — отказ с названием этого куска,
  результата нет.
- **Ненайденные номера** не отменяют найденного: найденные показываются,
  пропавшие называются строкой «Нет в библиотеке: …».
- **Порядок по убыванию номера везде:** поиск обоими способами, список
  Задач на Теме, `find_problems`. Сценарий «Порядок результата»
  `library-search` меняется.
- **Помощник.** У `find_problems` свойство `numbers` — массив номеров
  с тем же правилом (номера отменяют прочие условия, повтор — один номер,
  пустой массив — отказ). Ответ — объект `{problems, missing}`: найденные
  и ненайденные номера; без `numbers` список `missing` пуст.
- Документы вслед: сценарий С4 (`scenarios.md`) — подбор по номерам.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `library-search`: новый способ — прямой выбор по номерам со своей
  формой; порядок результата — по убыванию номера; ссылки на ADR-0064
  вместо ADR-0031 в изменяемых требованиях.
- `problem-catalog`: список Задач на Теме — по убыванию номера.
- `assistant-tools`: `find_problems` принимает `numbers` и называет
  ненайденные номера.

## Версия

`MINOR` — есть дельта спек (standards.md, «Версии»): 3.20.1 → 3.21.0.
Строка журнала: «`problem-search-by-numbers` — поиск Задач по списку

поиска и список Темы — по убыванию номера».

## Impact

- **Решения:** новая запись ADR-0064 заменяет ADR-0031 (у неё
  `status: Заменено`, `superseded_by: [64]`).
- **Стратегия:** не-цели не затронуты; работа — по отзыву вне горизонта
  редакции 3, как `warmup` и `work-without-file`.
- **Граница общего и личного: общее.** Поиск по общей библиотеке, читают
  все вошедшие; фильтра по владельцу нет и не появляется (ADR-0027),
  `ProblemRepository` параметра владельца не принимает
  (`SearchIsNotFilteredByOwnerTest` в силе).
- **Схема:** не меняется.
- **Код:** `ProblemNumbers` (новый — разбор поля), `ProblemService`
  (отбор по номерам с ненайденными), `ProblemRepository` (`order by p.id
  desc` в `findByTopic`, `findByIds`, `search`),
  `ProblemSearchController`, `templates/problem/search.html`,
  `ProblemTools.findProblems`; тесты `ProblemSearchScreenTest`,
  `ProblemSearchTest`, `ProblemSearchRepositoryTest`, `LibraryToolsTest`
  и опиравшиеся на возрастающий порядок.
- **Связи:** подбор под пробел (`mastery-views`) зовёт тот же поиск без
  номеров — меняется только порядок.
- **Признак готовности (карточка):** `?numbers=12, 3;7` показывает
  Задачи 12, 7, 3 в этом порядке; с `node` в том же адресе — те же три;
  несуществующий номер назван строкой «Нет в библиотеке»;
  `?numbers=3, пять` — отказ с «пять»; поиск по условиям и список Темы
  идут по убыванию номера; `find_problems` с `numbers` отвечает тем же
  набором.
