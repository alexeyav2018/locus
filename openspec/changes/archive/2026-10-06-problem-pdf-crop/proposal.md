# Proposal

## Why

Сборка PDF Задачи (ADR-0044) берёт страницы сборника только целиком,
а в сборниках задачи идут по нескольку на странице: страницы 47–48 тянут
за задачей 8 хвост задачи 7 и начало задачи 9, на снимке доски бывает
лишний угол. Отзыв учителя от 06.10.2026: без обрезки инструмент его
задачу не закрывает.

## What Changes

- Строка сборки получает **рамку**: Администратор открывает страницу
  источника картинкой, которую рисует сервер, и обводит на ней нужный
  кусок — мышью или пальцем на телефоне — либо оставляет страницу целиком.
  Кусок — одна страница результата; с одной страницы можно взять
  несколько кусков, повторив строку. Диапазоны целых страниц остаются
  как есть.
- Способ обрезки система выбирает по каждой странице источника:
  векторная страница PDF обрезается **векторно** — сужается видимая
  область, текст в куске остаётся текстом; страница-скан и картинка —
  **растром**: в результат ложится только прямоугольник рамки
  (скан — в 300 точках на дюйм, картинка — в своих пикселях). Скан
  распознаётся эвристикой: страница рисует одну картинку и не выводит
  текста. Переключателя способа у куска нет.
- Новый адрес показа страницы черновика картинкой — только своему
  черновику, только Администратору.
- Новая запись журнала
  [ADR-0045](../../context/adr/0045-obrezka-kuska-stranicy.md): способ
  обрезки по виду страницы и **принятый риск** — векторная обрезка
  прячет, а не удаляет содержимое за рамкой, и соседние задачи той же
  страницы остаются в файле невидимыми. ADR-0044 уточняется, не
  заменяется.

Граница общего и личного: как у `problem-pdf-assembly`. Результат — PDF
Задачи общей библиотеки, ведёт его Администратор, фильтра по владельцу
у Задачи нет и не появляется. Черновик сборки и отрисованные его
страницы принадлежат загрузившему: показ страницы чужого черновика
отклоняется так же, как несуществующего; новых методов репозитория без
`UserId` не появляется.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `problem-pdf-assembly`: требование об источниках допускает вместо
  диапазона целых страниц кусок одной страницы или картинки, обведённый
  рамкой; новые требования — способ обрезки по виду страницы с принятым
  риском и показ страницы черновика картинкой.

## Версия

`MINOR`: `1.1.0` → `1.2.0`. Есть дельта спек (`problem-pdf-assembly`),
«Ломает: нет». Не `MAJOR`: это доработка инструмента внутри заведения
Задачи, а не новая область.

## Impact

- Код `ru.locus.problem`: рамка (`CropFrame`) в строке порядка сборки
  и в куске сборки; `PdfAssembly` — кусок векторной страницы, кусок
  скана и картинки, распознавание скана, отрисовка страницы для показа;
  `AssemblyDraftService` — показ страницы своего черновика;
  `AssemblyDraftController` — адрес показа; `ProblemController` — разбор
  поля рамки.
- Шаблоны и скрипт: строка сборки `problem/assembly.html` — кнопка
  «обвести», картинка страницы, скрытое поле рамки; `static/js/locus.js`
  — рисование рамки указателем; `static/css/locus.css` — оформление.
- Схема и настройки: без изменений. Зависимостей новых нет (PDFBox
  и Thumbnailator уже есть).
- Документы: ADR-0045 (новая); `glossary.md` — термин «Рамка»;
  `antipatterns.md` — уточнение «разбор PDF» (распознавание скана
  по устройству страницы); `architecture.md` — показ страниц сервером;
  `CLAUDE.md` — статус и сводка решений при архивации;
  `domain-model.md`, `strategy.md`, `scenarios.md` — не затрагиваются.
