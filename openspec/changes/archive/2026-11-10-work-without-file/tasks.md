## 2. Экраны

- [x] 2.1 `templates/work/assignment.html`: у Работы без файла — плашка
  «без файла» (`badge badge--warn`) рядом с вердиктом, список «файл N»
  не выводится; блок «Файлы» у неё называется «Приложить файлы»,

  «без файла» и кнопка-ссылка «Приложить файлы» на

- [x] 2.3 `WorkScreenTest`: приём формой без файла с вердиктом — Работа
  принята, экран показывает «без файла» и «Приложить файлы»; после
  дополнения файлов пометки нет; удаление единственного файла —
  отказ новым текстом; прежняя проверка отказа «Нужен хотя бы один файл»

  возвращает выбранное» переносится на файл неподдерживаемого типа;
