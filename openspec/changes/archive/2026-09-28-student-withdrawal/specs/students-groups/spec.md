# Spec Delta

## ADDED Requirements

### Requirement: Ученик может выбыть и вернуться

Система SHALL хранить у Ученика состояние **выбыл** либо **действует**,
по умолчанию — действует. Учитель SHALL мочь пометить своего Ученика
выбывшим и вернуть выбывшего обратно в любой момент, без ограничений
и без влияния на что-либо ещё: Задания, Работы, отметки Владения
и членство в Группах не меняются.

Список Учеников (`/students`) SHALL по умолчанию показывать только
действующих и MUST предоставлять способ показать выбывших тем же
экраном, без отдельного адреса. Карточка выбывшего Ученика, его Задания,
Работы и отметки Владения остаются доступны без ограничений — выбытие
не прячет историю, а лишь убирает Ученика из повседневных списков
и выбора.

#### Scenario: Учитель помечает Ученика выбывшим

- **WHEN** Учитель помечает своего действующего Ученика выбывшим
- **THEN** Ученик получает состояние «выбыл»
- **AND** в обычном списке Учеников он больше не показывается

#### Scenario: Список по умолчанию скрывает выбывших

- **WHEN** Учитель открывает список Учеников, не запрашивая выбывших
- **THEN** показываются только действующие Ученики

#### Scenario: Выбывшие видны по запросу

- **WHEN** Учитель на экране списка Учеников запрашивает показ выбывших
- **THEN** показываются выбывшие Ученики этого Учителя

#### Scenario: Возврат из выбывших

- **WHEN** Учитель возвращает своего выбывшего Ученика
- **THEN** Ученик снова действует
- **AND** снова показывается в обычном списке Учеников

#### Scenario: Карточка выбывшего доступна

- **WHEN** Учитель открывает карточку своего выбывшего Ученика по прямому
  адресу
- **THEN** карточка открывается
- **AND** его Задания, Работы и отметки Владения доступны как обычно

#### Scenario: Выбытие не меняет состав Группы

- **WHEN** Учитель помечает выбывшим Ученика, состоящего в Группе
- **THEN** Ученик остаётся в составе этой Группы

#### Scenario: Чужого Ученика пометить нельзя

- **WHEN** Учитель Б пытается пометить выбывшим или вернуть Ученика
  Учителя А
- **THEN** операция не выполняется
- **AND** ответ такой же, как для несуществующего Ученика
