# Proposal

## Why

Задача заводится только из двух готовых PDF (`ProblemController.create`,
`ProblemService.create`), а исходники у учителя бывают трёх видов: готовый
PDF на одну задачу, набор картинок (фото листка, снимок экрана или доски)
и большой PDF-сборник, где задача занимает несколько страниц. Для двух
последних сегодня нужна посторонняя утилита — склеить картинки или вырезать
страницы. Отзыв учителя от 06.10.2026: заводить Задачу без неё.

## What Changes

- У каждого из двух слотов формы Задачи — при заведении и при замене файла,
  пока Задача не заморожена (ADR-0030), — появляется инструмент «собрать
  PDF»; рядом остаётся «приложить готовый PDF». Одновременно оба способа
  на одном слоте не принимаются.
- Источники сборки: картинки JPEG и PNG (каждая — одна страница размером
  по картинке, без подгонки под A4, без пережатия до предела сканов Работ,
  с разворотом по сведениям о съёмке) и PDF с указанием диапазона **целых**
  страниц. Источников у одного результата может быть несколько, порядок
  задаёт Администратор; один сборник может дать страницы и условию,
  и решению.
- Исходник загружается заранее и живёт **черновиком сборки** того, кто его
  загрузил, до сборки. Собранный PDF ложится в слот обычным путём
  хранилища; использованные черновики удаляются. Брошенный черновик
  убирается попутно: старше срока — при открытии инструмента, все — при
  старте приложения.
- Результат содержит только взятые страницы: ни картинок, ни шрифтов
  со страниц, которые не брались, в нём нет, даже если страницы сборника
  делят общий словарь ресурсов.
- Предел загрузки поднимается для инструмента (сборник — десятки мегабайт),
  прочие загрузки — Работы, готовые PDF, Теория — держат прежние 20 МБ
  на файл и 100 МБ на запрос.
- Новая запись журнала [ADR-0044](../../context/adr/0044-sborka-pdf-zadachi.md):
  Локус собирает PDF Задачи из картинок и целых страниц, не интерпретируя
  содержимого. ADR-0008 не пересматривается, а уточняется; уточняются
  антипаттерн «разбор PDF» и фраза требования file-storage «условие
  и решение хранятся ровно такими, какими их дал Администратор».

Граница общего и личного: результат — PDF Задачи общей библиотеки,
заводит его Администратор, фильтра по владельцу у Задачи нет и не
появляется. Черновик сборки — временный и принадлежит загрузившему:
чужих черновиков пользователь не видит ни одним запросом; у репозитория
черновиков нет метода без `UserId`, кроме двух поимённо названных уборок
(ADR-0044).

## Capabilities

### New Capabilities

- `problem-pdf-assembly`: сборка PDF слота Задачи из картинок и диапазонов
  страниц PDF — черновики сборки, их собственность и уборка, состав
  результата, предел загрузки инструмента.

### Modified Capabilities

- `file-storage`: требование о пережатии уточняет, что PDF не пережимается
  и не меняется хранилищем, а «ровно такими, какими их дал Администратор»
  включает PDF, собранный инструментом.
- `problem-catalog`: требование о составе Задачи допускает, что каждый
  из двух PDF приложен готовым или собран инструментом — и при заведении,
  и при замене.

## Версия

`MINOR`: `1.0.0` → `1.1.0`. Есть дельта спек (новая возможность
`problem-pdf-assembly`, правки `problem-catalog` и `file-storage`), «Ломает:
нет». Не `MAJOR`: это инструмент внутри заведения Задачи, а не целая
область библиотеки. Раздел дописан при архивации — правило версий
(ADR-0043) пришло в `develop`, пока изменение шло.

## Impact

- Код: новый набор классов в `ru.locus.problem` — черновик сборки
  (запись, идентификатор, репозиторий, сервис), сборка PDF на PDFBox,
  контроллер загрузки черновика; `ProblemController` и `ProblemService`
  принимают для слота либо готовый файл, либо порядок сборки; шаблон
  `problem/form.html` с первой в проекте точечной вставкой JavaScript
  (загрузка черновика и порядок строк, ADR-0020 её предусматривает);
  перехватчик общего предела загрузки.
- Зависимость: `org.apache.pdfbox:pdfbox` 3.x.
- Схема: таблица `assembly_draft` (миграция Liquibase).
- Настройки: `spring.servlet.multipart` поднимается до предела
  инструмента; новые `locus.upload.*` (общий предел) и
  `locus.problem.draft.*` (папка, срок).
- Документы: ADR-0044 (новая), `glossary.md` (термин «черновик сборки»),
  `antipatterns.md` (уточнение «разбор PDF»), `architecture.md` (рабочая
  папка черновиков, двухуровневый предел загрузки), `domain-model.md`
  (черновик вне сущностей модели — проверить и при необходимости
  упомянуть), `CLAUDE.md` (статус и сводка решений — при архивации).
