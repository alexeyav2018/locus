# Proposal

## Why

Сервер MCP и инструменты построены (`locus-mcp`), но запускать Помощника
некому: Реплика учителя пока не доходит до Claude Code на стенде, токен
Реплики выпускает только тест-двойник клиента. Без исполнителя Реплики
`assistant-chat` нечего показывать, а `problem-intake` — не к кому
подключать навык. `agent-spike` измерил нужные свойства Claude Code
(возобновление сеанса вместе с MCP, картинка из инструмента, SIGTERM
по пределу времени, `error_max_turns`) и дал стартовые пределы — 10 ходов
и 180 с на Реплику. Элемент бэклога `agent-runner`, верхний доступный.

## What Changes

- **Разговор и Реплика** (`AssistantConversation`, `AssistantTurn`) —
  хранимые записи личного контура: Разговор держит идентификатор сеанса
  Claude Code, Реплика — запрос, состояние, ответ, строки хода (вызовы
  инструментов), токены, стоимость, время и причину неудачи. Таблицы
  заводит это изменение, а не `assistant-chat`: без хранимой Реплики
  нечего пометить прерванной после перезапуска и не к чему возобновлять
  сеанс. Репозиторий — с `UserId` всюду, кроме одной уборки при старте.
- **Исполнитель Реплики**: на Реплику — процесс `claude -p --output-format
  stream-json` через `ProcessBuilder` в рабочем месте учителя; при
  продолжении Разговора — `--resume <сеанс>`. Токен Реплики выпускается
  на учителя перед запуском и отзывается по концу. Запрос уходит
  на стандартный ввод, окружение процесса — по белому списку. Разбор
  `stream-json`: сеанс — из первого события, вызовы инструментов — строки
  хода, итог — ответ, токены и стоимость.
- **Пределы и состояния**: предел времени и ходов из конфигурации
  (`locus.agent`, 180 с и 10 ходов); одна Реплика на учителя — вторая
  при идущей отклоняется; «Остановить» убивает процесс. Состояния:
  работаю, готово, не удалось, остановлено, прервано по времени,
  прервано по шагам, прервано перезапуском. При старте Локуса Реплики
  в «работаю» помечаются прерванными перезапуском — по образцу уборки
  черновиков.
- **Рабочее место** `agent/` в репозитории: `CLAUDE.md` Помощника (общие
  правила), `.mcp.json` с адресом и токеном из переменных окружения,
  `.claude/settings.json` с разрешениями только `mcp__locus__*`. Папка
  входит в сборку и разворачивается Локусом на учителя
  (`locus.agent.workspaces/<учитель>`, свой `CLAUDE_CONFIG_DIR`)
  при каждой Реплике.
- **Клетка**: встроенные инструменты Claude Code отключены, разрешены
  только инструменты сервера `locus`, сторонних конфигураций MCP нет.
- **Доступность**: при старте Локус сверяет `claude --version`
  с закреплённой (`locus.agent.version`) и проверяет, что в окружении
  есть ключ; отсутствие команды, расхождение версии или ключа Локус
  не роняют — Помощник недоступен с названной причиной. Страница
  `/assistant` в этом изменении только называет состояние доступности;
  разговор на ней строит `assistant-chat`.
- **Сторожевой тест навыков**: каждый инструмент `mcp__locus__<имя>`,
  названный в `agent/`, есть в реестре инструментов.
- **Тест-двойник команды** в тестовых ресурсах печатает заготовленный
  `stream-json` закреплённого формата: ответ, вызовы инструментов,
  зависание, падение, предел ходов.

## Capabilities

### New Capabilities

- `assistant-turns`: Реплики Помощника — Разговор и Реплика учителя,
  исполнение Реплики процессом Claude Code на одну Реплику в клетке
  рабочего места под токеном Реплики, пределы времени и ходов, одна
  Реплика на учителя, остановка, прерывание перезапуском, доступность
  Помощника с названной причиной, сверка навыков с реестром.

### Modified Capabilities

Нет. `assistant-tools` не меняет требований: токен Реплики и реестр
работают как построены, исполнитель ими только пользуется.

## Версия

`MINOR` — есть дельта спек, учитель на страницах изменения почти
не замечает: появляется только страница `/assistant` с состоянием
доступности, без ссылки в шапке (standards.md, «Версии»): 3.4.0 → 3.5.0.
Строка журнала: «`agent-runner` — исполнитель Реплики Помощника: процесс
Claude Code на одну реплику в клетке рабочего места `agent/` под токеном
учителя, с пределами времени и ходов, остановкой и пометкой прерванных
при перезапуске; Разговор и Реплика хранятся; доступность Помощника
с названной причиной».

## Impact

- Решения: новых записей журнала нет. Изменение исполняет ADR-0054
  (процесс на Реплику, уточнение ADR-0017, недоступность с причиной,
  закреплённая версия) и ADR-0057 (токен на Реплику, клетка, `agent/`,
  тест реестра). В рамках принятых записей в design.md решены: чьи
  таблицы Разговора и Реплики, какой ключ годится (ключ API или токен
  подписки — оба приходят из окружения Локуса), отдельное состояние
  «прервано по шагам», белый список окружения процесса, развёртывание
  рабочего места на каждую Реплику.
- Код: пакет `ru.locus.assistant` — `AssistantConversation`,
  `AssistantTurn`, их репозиторий и сервис, исполнитель процесса
  и разбор `stream-json`, сверка доступности, настройки
  `AgentProperties` (`locus.agent`), контроллер страницы `/assistant`;
  миграция с таблицами `assistant_conversation`, `assistant_turn`,
  `assistant_turn_step`; папка `agent/` в корне и её включение в сборку.
- Тесты: исполнение с двойником (готово с ответом и стоимостью,
  прервано по времени, не удалось с причиной, прервано по шагам,
  остановлено), вторая Реплика при идущей отклонена, после перезапуска
  незавершённая помечена прерванной, без команды страница называет
  причину, возобновление сеанса передаёт `--resume`, токен мёртв после
  Реплики; `OwnerIsRequiredByAssistantTest`,
  `AssistantIsFilteredByOwnerTest`; сторожевой тест навыков по реестру.
- Документы: `architecture.md` (исполнитель построен: рабочее место,
  клетка флагами, белый список окружения, ключ API или токен подписки),
  `glossary.md` (Разговор и Реплика — имена в коде настоящие, состояния
  Реплики), `standards.md` (процесс агента только в `ru.locus.assistant`;
  инструменты в `agent/` называются полным именем `mcp__locus__…`),
  `domain-model.md` (Разговор и Реплика в личном контуре), `CLAUDE.md`;
  карточка `assistant-chat` в бэклоге — таблицы уже есть.
- **Граница общего и личного**: данные — **личные**. Разговор и Реплика
  принадлежат учителю, фильтруются по владельцу во всех запросах, кроме
  уборки при старте; чужой Разговор не возобновить и чужую Реплику
  не остановить. Процесс действует от имени учителя токеном на Реплику;
  рабочее место и каталог настроек Claude Code — на учителя.
- Не ломает: новые таблицы, страницы прежние; на стенде без Claude Code
  Помощник просто недоступен с причиной. Оператору для работы Помощника
  нужно: установить Claude Code закреплённой версии, положить ключ
  в окружение Локуса, задать `locus.agent.workspaces`.
