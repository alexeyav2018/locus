## Why

Система не умеет хранить файлы, а хранить их придётся с первого же прикладного
элемента: Задача — это два PDF ([ADR-0008](../../context/adr/0008-zadacha-dva-pdf.md)),
Работа — обязательный скан или фотография
([ADR-0015](../../context/adr/0015-skany-rabot-hranyatsya.md)), Теоретический
материал — тоже файл ([ADR-0018](../../context/adr/0018-teoriya-v-pervoj-versii.md)).
Пока хранилища нет, библиотека не наполняется: `problem-catalog`
и `theory-materials` перечисляют `file-storage` в зависимостях
(`openspec/backlog.md:104`, `:106`).

Как хранить — уже решено
([ADR-0021](../../context/adr/0021-hranilishche-fajlov.md)): приватный бакет
объектного хранилища, отдача по временным подписанным ссылкам, доступ спрятан
за интерфейсом `FileStorage`. Это изменение не пересматривает решение,
а строит по нему.

Взять его сейчас можно и нужно: зависимостей у элемента нет, стоимость S,
а без него стоят три работы библиотеки.

## What Changes

- **Интерфейс `FileStorage`** — три операции над байтами: положить, получить
  временную ссылку, удалить. Он не знает ни о Задачах, ни о Работах: что
  именно лежит по ключу, известно только вызывающему.
- **Реализация на объектном хранилище**, S3-совместимая. Та, что пойдёт в бой.
- **Реализация на локальной папке** — для разработки и для случая, когда
  внешнее хранилище недоступно или не нужно.
- **Наружу — только временная подписанная ссылка.** Обе реализации соблюдают
  это одинаково: у локальной появляется адрес отдачи с подписью и сроком, иначе
  «прямой доступ без подписи не работает» проверялось бы только у одной из двух.
- **Пережатие изображений — отдельный компонент**, а не операция хранилища.
  Пережимается снимок, но не PDF; знание о том, что именно пришло, есть
  у сервиса и не должно протекать в `FileStorage`
  ([architecture.md](../../context/architecture.md), таблица слоёв).
- **Один набор тестов на контракт, прогоняемый по обеим реализациям.**
  S3-реализация проверяется на MinIO, поднятом Testcontainers, — так же, как
  сейчас поднимается PostgreSQL. Иначе единственный код, который повезёт файлы
  учеников, окажется единственным непроверенным, и сломается он молча — при
  первой попытке учителя открыть работу.

Что в изменение **не** входит:

- привязка файлов к Задачам, Работам и Теории — этих сущностей ещё нет,
  и таблиц под них изменение не заводит;
- пометки на изображении и скан к части задачи — отложено
  ([strategy.md](../../context/strategy.md), «Что отложено и когда вернёмся»);
- боевой бакет, ключи сервисного аккаунта и резервное копирование файлов —
  это `deployment-backup` (`openspec/backlog.md:110`). Изменение готовит
  параметры настройки, но не настраивает боевую среду.

Новых решений, требующих записи в журнале, изменение не принимает.
Размещение пережатия вне `FileStorage` и проверка обеих реализаций одним
набором тестов выводятся из уже принятых
[ADR-0021](../../context/adr/0021-hranilishche-fajlov.md),
[architecture.md](../../context/architecture.md)
и [standards.md](../../context/standards.md); передумать в обоих случаях стоит
перенос вызова, а критерий журнала — «дорого ли будет передумать»
([adr/README.md](../../context/adr/README.md)).

## Capabilities

### New Capabilities

- `file-storage`: хранение файлов — укладка, отдача по временной подписанной
  ссылке, удаление, пережатие изображений при загрузке и поведение при
  недоступном хранилище.

### Modified Capabilities

Нет: ни `application-startup`, ни `users-and-roles` требований не меняют.
Хранилище — новая возможность, ничего из существующего поведения она
не переопределяет.

## Impact

**Код.** Новый пакет `ru.locus.file`: интерфейс, две реализации, компонент
пережатия, адрес отдачи для локальной реализации. Правка `SecurityConfig`
(`src/main/java/ru/locus/security/SecurityConfig.java`) — адрес отдачи
защищается подписью, а не сеансом, иначе ссылку нельзя открыть вне браузера
учителя.

**Зависимости.** `pom.xml`: AWS SDK v2 (`s3`) для боевой реализации,
`testcontainers-minio` для тестов, Thumbnailator для пережатия — он
разворачивает снимок по сведениям о съёмке, чего чистый `ImageIO` не делает
([design.md](design.md), «Пережатие»).

**Настройки.** `application.yaml`: выбор реализации, срок жизни ссылки,
папка для локальной, параметры бакета для объектной. Боевые значения приходят
из окружения и здесь не задаются.

**База.** Не затрагивается: миграций изменение не добавляет.

**Граница общего и личного.** Не затрагивает. Хранилище не знает, чьи файлы,
и ключ владельца в его сигнатурах не появляется — ни у одной реализации.
Права проверяются выше, в сервисе, который решает, выдать ли ссылку
([ADR-0027](../../context/adr/0027-mehanizm-granicy-obshchego-i-lichnogo.md)).
