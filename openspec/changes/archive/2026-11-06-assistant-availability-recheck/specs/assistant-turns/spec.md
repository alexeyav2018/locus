## MODIFIED Requirements

### Requirement: Помощник без команды недоступен с причиной

При старте Локус SHALL проверить, что команда Claude Code есть и её
версия совпадает с закреплённой, и что в окружении есть ключ — ключ API
либо токен подписки. При любом провале Помощник недоступен, а остальная
система MUST работать как прежде: старт не прерывается. Страница
Помощника называет состояние: «Помощник доступен» либо «Помощник
недоступен» с причиной; начало Реплики при недоступном Помощнике
отклоняется с той же причиной
([ADR-0054](../../context/adr/0054-pomoshchnik-claude-code-na-stende-process-na-repliku.md)).

Пока Помощник недоступен, Локус SHALL проверять заново при открытии
страницы Помощника и при запросе Реплики, и удавшаяся проверка
возвращает Помощника без перезапуска Локуса. Доступного Помощника
Локус MUST NOT проверять заново: команда при обращениях не запускается.
Две проверки разом MUST NOT идти: обращение, заставшее идущую проверку,
её не ждёт и получает прежний итог. Сами по себе, без обращения учителя,
проверки MUST NOT запускаться.

#### Scenario: Нет команды

- **WHEN** по пути команды Claude Code ничего нет
- **THEN** Локус поднимается, страница Помощника называет причину —
  команда не найдена

#### Scenario: Чужая версия

- **WHEN** команда отвечает версией, отличной от закреплённой
- **THEN** Помощник недоступен, причина называет обе версии

#### Scenario: Нет ключа

- **WHEN** в окружении Локуса нет ни ключа API, ни токена подписки
- **THEN** Помощник недоступен, причина называет обе переменные

#### Scenario: Всё на месте

- **WHEN** команда отвечает закреплённой версией и ключ есть
- **THEN** страница Помощника говорит, что он доступен

#### Scenario: Страница возвращает Помощника

- **WHEN** проверка при старте не удалась, команда починена, и учитель
  открывает страницу Помощника
- **THEN** страница говорит, что Помощник доступен, и показывает форму
  запроса — Локус не перезапускался

#### Scenario: Запрос возвращает Помощника

- **WHEN** проверка при старте не удалась, команда починена, и учитель
  отправляет запрос, не открывая страницу заново
- **THEN** Реплика начинается

#### Scenario: Сбой продолжается

- **WHEN** Помощник недоступен, команда всё ещё не отвечает, и учитель
  отправляет запрос
- **THEN** запрос отклоняется с причиной, Реплики нет

#### Scenario: Доступный не проверяется

- **WHEN** Помощник доступен, и учитель открывает страницу и отправляет
  запрос
- **THEN** на `--version` команда заново не запускается

#### Scenario: Проверка уже идёт

- **WHEN** Помощник недоступен, проверка идёт, и приходит второе обращение
- **THEN** второе обращение сразу получает прежний итог, а команда
  запущена один раз
