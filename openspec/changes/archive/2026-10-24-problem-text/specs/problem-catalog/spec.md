## MODIFIED Requirements

### Requirement: Задача состоит из двух PDF и разметки

Система SHALL хранить Задачу как два файла PDF — условие и решение — вместе
с разметкой. Оба файла обязательны: Задача без любого из них не сохраняется.

Задача бывает двух видов, живущих в одной библиотеке без срока
([ADR-0055](../../context/adr/0055-tekst-zadachi-pervichen-pdf-otrisovka.md)):
**без текста** — оба PDF приложены готовыми или собраны, формулы живут
внутри PDF, и система их не хранит и не разбирает; **с текстом** — у неё
есть Текст Задачи, и оба PDF есть отрисовка этого текста, которую делает
сама система (возможность `problem-text`). Для всего, что читает PDF
Задачи, — просмотра, Заданий, страниц картинками — виды не различаются.

Обязательность обоих файлов: Задача без решения обнаружит свою неполноту
только в момент проверки Работы ученика, когда решение понадобится,
а искать его будет поздно.

Задача принадлежит общей библиотеке и существует независимо от того, кому
и когда она выдавалась.

У Задачи без текста каждый из двух PDF Администратор выбирает одним полем
слота — и при заведении, и при замене файла: нетронутый PDF ложится как
есть, а из картинок, диапазонов и кусков страниц PDF собирается
инструментом сборки (возможность `problem-pdf-assembly`,
[ADR-0044](../../context/adr/0044-sborka-pdf-zadachi.md),
[ADR-0049](../../context/adr/0049-odno-pole-fajla-na-slot-zadachi.md)).
Для Задачи способ безразличен: она хранит два PDF, а не то, из чего они
сделаны.

#### Scenario: Задача заведена

- **WHEN** Администратор заводит Задачу без текста, приложив PDF условия
  и PDF решения и указав разметку
- **THEN** Задача появляется в библиотеке
- **AND** оба файла доступны при её просмотре

#### Scenario: Нет PDF решения

- **WHEN** Администратор заводит Задачу без текста, приложив только PDF
  условия
- **THEN** Задача не создаётся
- **AND** сообщается, какого файла не хватает

#### Scenario: Нет PDF условия

- **WHEN** Администратор заводит Задачу без текста, приложив только PDF
  решения
- **THEN** Задача не создаётся

#### Scenario: Задача с собранным условием и готовым решением

- **WHEN** Администратор заводит Задачу, собрав PDF условия из картинок
  и приложив готовый PDF решения
- **THEN** Задача появляется в библиотеке
- **AND** при её просмотре доступны оба файла, как у Задачи из двух
  готовых PDF

#### Scenario: Задача с текстом читается как любая

- **WHEN** Учитель открывает Задачу с текстом
- **THEN** ему доступны PDF условия и PDF решения тем же способом,
  что у Задачи без текста

### Requirement: Файлы Задачи не остаются в хранилище без Задачи

Система SHALL удалять из хранилища файл, переставший принадлежать Задаче:
оба PDF и Улики при удалении Задачи, заменённый файл при замене,
прежнюю отрисовку слота при правке его текста.

Кроме кода Задачи, распознать ненужный файл некому: хранилище не знает,
чьё содержимое лежит по ключу и что это вообще такое
([file-storage](../file-storage/spec.md)). Оставленный файл
уже ничем не адресуется — ссылки на него нет нигде, — и отличить его
от нужного впоследствии невозможно.

#### Scenario: Удаление Задачи уносит оба файла

- **WHEN** Администратор удаляет Задачу
- **THEN** ни условие, ни решение больше не отдаются по ранее выданным
  ссылкам

#### Scenario: Удаление Задачи с текстом уносит Улики

- **WHEN** Администратор удаляет Задачу с текстом и Уликами
- **THEN** ни отрисовки, ни Улики больше не отдаются по ранее выданным
  ссылкам

#### Scenario: Замена PDF

- **WHEN** Администратор заменяет PDF решения другим файлом
- **THEN** Задача отдаёт новое решение
- **AND** прежний файл в хранилище не остаётся

#### Scenario: Второй файл при замене не задет

- **WHEN** Администратор заменяет PDF решения
- **THEN** PDF условия остаётся прежним, байт в байт

#### Scenario: Правка текста не оставляет прежней отрисовки

- **WHEN** Администратор правит текст решения Задачи с текстом
- **THEN** прежний PDF решения в хранилище не остаётся
- **AND** PDF условия остаётся прежним, байт в байт
