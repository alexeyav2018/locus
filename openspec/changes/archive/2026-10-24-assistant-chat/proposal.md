# Proposal

## Why

Исполнитель Реплики построен (`agent-runner`): Реплика доходит
до Claude Code на стенде, исполняется в клетке под токеном учителя
и хранится вместе с ходом и стоимостью. Но учителю начать её неоткуда —
страница `/assistant` только называет доступность, а пункта в шапке нет.
Без страницы разговора Помощник не существует для учителя, а навыку
`intake-skill` некуда привести учителя с листом. Элемент бэклога
`assistant-chat`, верхний доступный.

## What Changes

- **Страница разговора** `/assistant` вместо страницы доступности:
  Реплики Разговора по порядку — запрос учителя, состояние словом
  (семь состояний `TurnState`), ответ Помощника, ход (вызовы
  инструментов) и стоимость; у «прервано по шагам» — подсказка
  продолжить в том же Разговоре; у неудачи и прерываний — причина.
- **Пока Реплика идёт**, страница перечитывается сама (`meta refresh`,
  необязательный параметр общего `shell :: head`), поля ввода нет,
  есть «Остановить». Завершилась — ответ на месте, перечитывания нет.
- **Какой Разговор показан:** с идущей Репликой, иначе последний, если
  в нём говорили сегодня; иначе пустой — первая реплика нового дня
  начинает новый Разговор. «Новый разговор» — кнопкой; прежние
  Разговоры читаются по `?conversation=` из списка «Прежние разговоры».
- **Файл в реплике** (у Администратора — Черновики сборки и заведение
  Задач его): поле файла с `accept` под камеру планшета кладёт снимок
  или PDF Черновиком сборки того же учителя, а Помощник получает
  в запросе «загружен черновик сборки N». PDF — под пределом
  инструмента (`@LargeUpload`).
- **Ответ Помощника — Markdown** с белым списком: сырой HTML — текстом,
  картинки — подписью, ссылки — только внутренние, с `from` на этот
  Разговор; внешняя ссылка остаётся текстом.
- **Раздел «Помощник» в шапке**, в группе «Кабинет»: Разговоры —
  личные. Группа видна и Администратору, но у него в ней только
  «Помощник».
- **Пустое состояние** с подсказкой; «Помощник недоступен: причина» —
  без формы, прежние Разговоры при этом читаются.

## Capabilities

### New Capabilities

- `assistant-chat`: страница разговора с Помощником — показ Разговора
  и его Реплик с состоянием, ходом и стоимостью, отправка реплики
  с файлом, остановка, самообновление идущей Реплики, выбор
  показанного Разговора и прежние Разговоры, безопасный показ ответа
  Markdown, раздел в шапке, недоступность без формы.

### Modified Capabilities

Нет. `assistant-turns` не меняет требований: страница по-прежнему
называет недоступность с причиной и «Помощник доступен», а Реплики
начинаются и останавливаются тем же сервисом.

## Версия

`MINOR` — есть дельта спек (standards.md, «Версии»): 3.5.0 → 3.6.0.
`MAJOR` не предлагается: новой области данных нет — Разговоры и Реплики
построил `agent-runner`, — интерфейс прежний, а сценарий «заводить
задачи с листа» учитель получит целиком только с `problem-intake`
и `intake-skill`; эта страница — канал к нему (след решения — design.md,
Р12). Строка журнала: «`assistant-chat` — страница разговора
с Помощником: раздел в шапке, реплики с состоянием, ходом и стоимостью,
самообновление и остановка идущей реплики, снимок листа Черновиком
сборки, ответ Markdown только с внутренними ссылками, прежние
разговоры».

## Impact

- Решения: новых записей журнала нет. Изменение исполняет ADR-0041
  (единый CSS, без своих стилей и скриптов — самообновление без
  скрипта), ADR-0042 (вторичное по кнопке, `from`, `ReturnTo`),
  ADR-0054 (одна Реплика на учителя, недоступность с причиной)
  и ADR-0056 (файл ложится Черновиком сборки через его сервис).
  В design.md решены: какой Разговор показан по умолчанию, у кого поле
  файла, как ответ превращается в HTML и куда ведут ссылки, место
  пункта в шапке, как Помощник узнаёт о черновике без зависимости
  `ru.locus.assistant` от области Задач.
- Код: `AssistantController` (страница, отправка, остановка),
  `AssistantService` (Разговор для показа, список прежних, идущая
  Реплика учителя, вложение), `AssistantRepository` (свои Разговоры
  и последний, идущая Реплика — все с `UserId`), показ ответа Markdown
  (`AnswerMarkdown`), вопрос `TurnAttachments` с ответчиком в области
  Задач; шаблон `assistant/page.html`, `fragments/shell.html`
  (параметр обновления, пункт шапки), `ShellAdvice` (раздел),
  `locus.css` (Разговор и Реплика); `Addresses`.
- Тесты: страница с двойником — «работаю» с обновлением, после
  завершения ответ и стоимость без него; остановка; снимок стал
  Черновиком сборки вошедшего, запрос называет черновик; внешняя
  ссылка в ответе — текст, внутренняя — с `from`; чужой Разговор —
  404; без команды — причина и нет формы; пункт шапки; правило
  Разговора по умолчанию на `TestClock`; изоляция новых методов
  репозитория.
- Документы: `glossary.md` (страница Разговора, вложение), `ux-concept.md`
  не меняется — страница по его правилам; `architecture.md` (Помощник
  доступен учителю со страницы); `CLAUDE.md`; бэклог — статус.
- **Граница общего и личного**: данные — **личные**. Разговоры
  и Реплики — учителя, каждый новый запрос репозитория — с владельцем,
  чужой Разговор неотличим от несуществующего (404). Черновик сборки
  из реплики — загрузившего, как у формы Задачи; заводит его сервис
  черновиков с его правами (Администратор). В библиотеку страница
  ничего не пишет — это делают инструменты Помощника по правам учителя.
- Не ломает: схема прежняя, страница `/assistant` расширяется.
