# Proposal

## Why

Сеанс учителя 25.10.2026: Задача № 28 выдана Группе «А+У» дважды —
Раздачи № 2 (23:12 МСК) и № 3 (23:19 МСК). Между ними «Задания Ученика»
отвечали 400 (починено `back-link-gaps`), выдача показалась неудачной,
и учитель выдал заново. Форма выдачи `/assignments/new` не говорит,
что Задача этому адресату уже выдавалась (`AssignmentController.java:185-191`
даёт форме Задачи, Учеников и Группы, о прежних выдачах ничего), —
повтор замечается только по задвоенному списку Заданий. Запрещать повтор
нельзя: та же Задача может выдаваться снова намеренно.

Элемент бэклога `assignment-repeat-hint`, верхний доступный.

## What Changes

- **Подсказка о прежних выдачах на форме выдачи.** У каждой выбранной
  Задачи, которую вошедший Учитель уже выдавал, — строка «Уже выдана: …»:
  выдача Раздачей — именем Группы на момент выдачи и датой, выдача
  отдельному Ученику — его именем и датой. Новые первыми, не больше трёх,
  остальные — «и ещё N». Задача, ни разу не выданная этим Учителем,
  строки не получает; выдачи других Учителей не показываются.
- **Выдача не меняется.** Повтор не отклоняется и не требует
  подтверждения (решение владельца 26.10.2026 в карточке).

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `assignments`: новое требование — форма выдачи показывает у каждой
  Задачи прежние выдачи вошедшего Учителя, повтор при этом проходит.

## Версия

`MINOR` — есть дельта спек (standards.md, «Версии»): 3.15.0 → 3.16.0.
Строка журнала: «`assignment-repeat-hint` — форма выдачи показывает
у каждой Задачи, кому и когда вошедший Учитель её уже выдавал;
повтор по-прежнему проходит».

## Impact

- Решения: новых записей журнала нет. Подсказка без запрета —
  решение владельца в карточке; ADR-0037 (удаление Раздачи, пока нет
  Работы) и ADR-0016 (Раздача помнит имя Группы текстом) не меняются.
  Как сжимается длинный перечень и откуда берётся имя адресата —
  design.md.
- Граница общего и личного: **личное**. Прежние выдачи — Задания
  вошедшего Учителя; новый метод `AssignmentRepository` принимает
  `UserId` и в класс ADR-0036 не входит, `OwnerIsRequiredByAssignmentsTest`
  исключением не расширяется. Задачи формы — общая библиотека, их выборка
  прежняя.
- Файлы: `AssignmentRepository` (новый метод), новый тип прежней выдачи
  в `ru.locus.assignment`, `AssignmentService` (новая операция),
  `AssignmentController.renderForm`, `templates/assignment/form.html`,
  `static/css/locus.css`; тесты `AssignmentRepositoryTest`,
  `AssignmentScreenTest`.
- Признак готовности: тесты формы — Задача, выданная Группе, — строка
  с именем Группы и датой; выданная Ученику напрямую — с его именем;
  выданная другим Учителем — без строки; повторная выдача той же Задачи
  тому же адресату проходит.
