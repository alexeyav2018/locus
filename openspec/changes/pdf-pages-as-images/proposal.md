## Why

Учитель открывает условие или решение Задачи на планшете — вместо PDF
на странице просмотра наша же запасная надпись «Этот браузер не показывает
PDF на странице» и кнопка «Открыть PDF», которая файл только скачивает
(обращение 10.10.2026, класс **Б**). Браузеры на Android встроенного
просмотрщика PDF не имеют: `<object type="application/pdf">`
(`src/main/resources/templates/file/viewer.html:27`) показывает запасное
содержимое, а ссылка на файл уводит его из системы. Посмотреть Задачу
в Локусе на планшете нельзя вовсе, а это основное действие с библиотекой.

## What Changes

- Страница просмотра показывает PDF **столбцом картинок страниц**,
  отрисованных на сервере PDFBox (как страница черновика сборки), вместо
  `<object>`. Картинки грузятся по мере прокрутки (`loading="lazy"`), без
  скрипта. Кнопка «Открыть PDF» остаётся.
- Показываются первые 20 страниц; у длинного файла — строка «Показаны
  первые 20 из N страниц» с «Открыть PDF» для остальных.
- PDF, который не разбирается или закрыт паролем, страница не роняет:
  «Показать этот PDF на странице не удалось» и «Открыть PDF».
- Новые адреса картинки страницы, с теми же правилами доступа, что у своей
  страницы просмотра: `/problems/{id}/condition/pages/{n}`,
  `/problems/{id}/solution/pages/{n}`, `/theory/{id}/view/pages/{n}`,
  `/works/{id}/files/{fileId}/pages/{n}`. Чужая Работа, несуществующий файл
  и страница вне файла — 404.
- `FileStorage` получает операцию чтения содержимого по ключу (объектное
  хранилище — `GetObject`, папка — уже имеющееся чтение).
- Заголовок `X-Frame-Options` возвращается к `DENY`: встраивать в рамку
  больше нечего.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `interface-navigation`: требование «Файлы просматриваются внутри системы» —
  PDF показывается картинками страниц вместо встроенного просмотра; картинка
  страницы отдаётся по правилам доступа страницы просмотра; предел страниц
  и неразбираемый PDF.

## Impact

- Решения: новая запись [ADR-0052](../../context/adr/0052-pdf-na-stranice-prosmotra-kartinkami-stranic.md)
  («Предложено») — уточняет ADR-0042 в части PDF и рамки, расширяет ADR-0021
  операцией чтения.
- Код: `ru.locus.file` — `FileStorage.read`, его реализации, новый
  отрисовщик `PdfPages`, `FileView`; контроллеры `ProblemController`,
  `TheoryController`, `StudentWorkController` — адреса картинок страниц;
  `SecurityConfig` — рамка; шаблон `file/viewer.html` и `locus.css`.
- Тесты: `FileViewerScreenTest` и новые проверки адресов картинок страниц;
  `LocalFileStorageTest`/`ObjectFileStorageTest` — чтение.
- Документы: `architecture.md` (у хранилища есть чтение; показ PDF
  картинками), `ux-concept.md` при упоминании встроенного PDF.
- **Граница общего и личного** правил не меняет. PDF Задач и теории
  (общее) — картинки страниц видны вошедшим, без фильтра по владельцу;
  файлы Работ (личное) — только владельцу Работы, через тот же сервис
  `StudentWorkService` с `UserId` из `CurrentUser`, что и страница просмотра.
  Хранилище владельцев не знает, как и прежде.
- Не ломает: данных и схемы не меняет.
