## MODIFIED Requirements

### Requirement: Ячейка существует только у пары, порождённой Задачей

Система SHALL принимать отметку только на паре «Тема × Метод», по которой
у Ученика есть Задача: Темы Задачи, перемноженные на её Методы, — и только
из одного из двух оснований: Задания этого Ученика с принятой Работой
по этой Задаче либо Разминки, в которой Ученик участвует, с этой Задачей
в составе ([ADR-0061](../../context/adr/0061-razminka-svoya-zapis-vtoroe-osnovanie-otmetki.md)).
Ячейки порождаются употреблением, а не перемножением словарей
(инвариант 4): пара, под которой нет ни одной Задачи, отметки принять
MUST NOT.

К Работе и к Разминке отметка не привязана: она стоит на паре, а не
на решении, и удаление Работы
([ADR-0038](../../context/adr/0038-rabota-odna-na-paru-i-udalyaetsya-svobodno.md))
или Разминки отметку не снимает.

#### Scenario: Отметка на паре из разметки Задачи

- **WHEN** по Задаче, размеченной Темами А и Б и Методами X и Y, принята
  Работа, и Учитель ставит отметку на паре «Б × X»
- **THEN** отметка принята

#### Scenario: Пара не из разметки Задачи

- **WHEN** Учитель пытается поставить отметку на паре «Тема × Метод», где
  Тема или Метод не входят в разметку Задачи, по которой принята Работа
- **THEN** отметка отклоняется
- **AND** ни одна ячейка не меняется

#### Scenario: Работы по Задаче ещё нет

- **WHEN** Учитель пытается поставить отметку по Задаче Задания, Работа
  по которой не принята
- **THEN** отметка отклоняется

#### Scenario: Работа удалена — отметка осталась

- **WHEN** после простановки отметки Учитель удаляет Работу
- **THEN** отметка на паре по-прежнему стоит

#### Scenario: Отметка по Разминке без Работы

- **WHEN** у Ученика нет ни одной Работы, а на странице Разминки с Задачей,
  размеченной парой «А × X», Учитель ставит ему на этой паре «владеет»
- **THEN** отметка принята

#### Scenario: Пара не из Задач Разминки

- **WHEN** Учитель пытается поставить участнику Разминки отметку на паре,
  которой нет в разметке ни одной Задачи этой Разминки
- **THEN** отметка отклоняется
- **AND** итоги, сохраняемые тем же действием, не меняются

### Requirement: Справка по истории решений

Система SHALL у каждой ячейки-кандидата показывать справку по двум
основаниям порознь — «Работы: N из M · разминки: K из L»
([ADR-0061](../../context/adr/0061-razminka-svoya-zapis-vtoroe-osnovanie-otmetki.md)):
M — число **проверенных** Работ этого Ученика по Задачам, размеченным
**и** этой Темой, **и** этим Методом, N — те из них, что «верно»;
L — число Итогов Разминки этого Ученика по Задачам с этой парой,
K — те из них, что «справился». Непроверенные Работы и пустые клетки
Разминок в справку не входят
([ADR-0039](../../context/adr/0039-otmetka-tolko-s-suzhdeniem.md)).
Считаются Работы у всех Заданий Ученика и итоги всех его Разминок,
а не только текущих. Одной суммы по обоим основаниям система MUST NOT
показывать.

Справка — подсказка, а не основание: система по ней ничего не выводит.

#### Scenario: Справка считает проверенные Работы Ученика

- **WHEN** у Ученика по Задачам с парой «Тема × Метод» принято три Работы
  с вердиктами «верно», «неверно», «верно» и одна без вердикта, а Разминок
  нет
- **THEN** у ячейки этой пары показано «Работы: 2 из 3 · разминки: 0 из 0»

#### Scenario: Справка считает итоги Разминок порознь

- **WHEN** у Ученика по Задачам с парой есть одна Работа с вердиктом
  «верно» и два Итога Разминки — «справился» и «не справился», — а третья
  клетка Разминки пустая
- **THEN** у ячейки показано «Работы: 1 из 1 · разминки: 1 из 2»

#### Scenario: Справка без Работ

- **WHEN** у Ученика нет ни проверенных Работ, ни Итогов Разминки
  по Задачам с этой парой
- **THEN** у ячейки показано «Работы: 0 из 0 · разминки: 0 из 0»

### Requirement: Учитель видит и ведёт только свои отметки

Система SHALL показывать и принимать отметки только на Учениках вошедшего
Учителя: чужой Ученик, чужое Задание, чужая Работа и чужая Разминка для
него неотличимы от несуществующих
([ADR-0027](../../context/adr/0027-mehanizm-granicy-obshchego-i-lichnogo.md)).
Отметки двух Учителей на одних и тех же парах библиотеки независимы.
Простановка доступна только Пользователю с ролью Учителя; Администратору
без этой роли отметки не показываются и не принимаются
([ADR-0005](../../context/adr/0005-roli-administrator-uchitel.md)).

#### Scenario: Простановка на чужом Задании

- **WHEN** Учитель Б пытается поставить отметку по Работе Задания Учителя А
- **THEN** он получает «не найдено»
- **AND** отметки Учителя А не меняются

#### Scenario: Простановка на чужой Разминке

- **WHEN** Учитель Б пытается поставить отметку участнику Разминки Учителя А
- **THEN** он получает «не найдено»
- **AND** отметки Учителя А не меняются

#### Scenario: Отметки двух Учителей независимы

- **WHEN** Учителя А и Б ставят отметки своим Ученикам на одной и той же
  паре библиотеки
- **THEN** каждый видит только свои

#### Scenario: Администратор без роли Учителя

- **WHEN** Пользователь только с ролью Администратора пытается поставить
  отметку
- **THEN** ему отказано

## ADDED Requirements

### Requirement: Ячейки-кандидаты стоят на странице Разминки

Система SHALL на странице Разминки показывать у каждого участника ячейки
«Тема × Метод» — пары из разметки Задач Разминки, каждая один раз, даже если
её дают несколько Задач, — с текущим значением и справкой по истории
решений, по умолчанию «без изменения». Простановка SHALL быть выборочной
и сохраняться тем же действием, что и итоги этого участника, одной
транзакцией: отказ одного отменяет оба. Предзаполнения нет, итог
на отметки не влияет
([ADR-0011](../../context/adr/0011-otmetka-na-pare.md),
[ADR-0061](../../context/adr/0061-razminka-svoya-zapis-vtoroe-osnovanie-otmetki.md)).
Ячейки — без таблиц и фиксированных ширин: экран под телефон.

#### Scenario: Ячейки участника

- **WHEN** в Разминке две Задачи: одна размечена «А × X», другая —
  «А × X» и «Б × X»
- **THEN** у каждого участника показаны две ячейки — «А × X» и «Б × X»
- **AND** в каждой выбрано «без изменения»

#### Scenario: Итоги и отметки одним сохранением

- **WHEN** Учитель ставит участнику «справился» по Задаче и «владеет»
  на ячейке «А × X» и сохраняет
- **THEN** итог и отметка записаны оба

#### Scenario: Отказ отменяет и итоги

- **WHEN** в одном сохранении итог участника верный, а отметка — на паре
  не из Задач Разминки
- **THEN** не записаны ни итог, ни отметка
