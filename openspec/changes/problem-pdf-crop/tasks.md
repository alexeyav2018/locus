## 1. Рамка и порядок сборки

- [x] 1.1 `CropFrame(left, top, width, height)` — доли от 0 до 1, отказ
      рамке за пределами страницы и нулевой ширины или высоты; разбор
      и запись поля формы «л;в;ш;в» (`parse`, `formValue`); перевод
      в прямоугольник PDF `on(PDRectangle visible, int rotation)`
      (design.md, «Рамка — доли показанной страницы»); проверить —
      `CropFrameTest`: границы, разбор, перевод для поворотов 0/90/180/270
- [x] 1.2 `PdfAssemblyOrder.Line` получает `frame` (может быть `null`),
      `PdfAssemblyPart.Image` — `frame`, новый `PdfAssemblyPart.Piece(file,
      name, page, frame)`; `AssemblyDraftService.assemble` превращает
      строку с рамкой в кусок и отклоняет рамку при `from != to`
      («рамка ставится на одну страницу»); `AssemblyRow` несёт рамку,
      `rows` её возвращает; проверить — `AssemblyDraftServiceTest`:
      рамка на диапазоне отклоняется, рамка возвращается в строки
- [x] 1.3 `ProblemController.order` разбирает `conditionCrop` /
      `solutionCrop` (пустое — без рамки, испорченное — отказ формы)
      во всех трёх обработчиках (заведение, замена условия, замена
      решения); проверить — компиляция и существующие тесты сборки
      зелёные (`mvn test -Dtest='Assembl*Test,PdfAssemblyTest'`)
