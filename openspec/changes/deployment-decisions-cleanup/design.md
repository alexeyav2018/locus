## Context

Мотивация — proposal.md. Записи журнала неизменяемы
([ADR-0022](../../context/adr/0022-kontekst-kak-ishodniki.md), `CLAUDE.md`,
«Журнал решений»), поэтому ссылки на `deployment-backup` в текстах ADR-0020,
ADR-0023, ADR-0024 остаются; поправить их можно только новой записью,
которая их объясняет. Граница общего и личного: не затрагивается.

## Goals / Non-Goals

**Goals:** у правил эксплуатации назван держатель; ни один изменяемый
документ и ни один комментарий в коде не называет отменённый элемент будущей
работой.

**Non-Goals:** описание самого стенда (как поднят, где копии) — его знает
только владелец; репетиция апгрейд-пути на копии боевой базы; оснастка
тегов `tagDatabase`.

## Decisions

Решения сессии батча без вопроса владельцу (правило вопросов: есть
предпочтительный вариант, в котором уверена). Владелец видит их на гейте
вместе с ADR-0051.

### Р1. Развилка карточки — вариант (а): новая запись журнала

Под вопросом: (а) запись «эксплуатация ведётся вне репозитория»;
(б) то же плюс эксплуатационная заметка о стенде, которую пишет или диктует
владелец; (в) только комментарии и `architecture.md`, журнал не трогать.

Выбрано (а). (в) не годится: ADR-0024 утверждает «пока `deployment-backup`
не сделан, система живёт локально» — это уже неправда, и без новой записи
действующий журнал так и будет её утверждать; держатель правил обновления
остаётся неназванным. (б) содержит всё из (а) и сверх того факты, которых
в репозитории нет и которые сессия добыть не может; заметку владелец может
добавить в любой момент поверх (а), запись её не запрещает. Значит, (а) —
общая часть обоих вариантов, не отрезающая (б).

### Р2. Без формальной замены ADR-0020/0023/0024

Под вопросом: ставить ли старым записям `Заменено` с `superseded_by: [51]`.
Скрипт индекса разрешает `superseded_by` только у `Заменено`/`Отменено`,
а сами решения (стек, оснастка, обновление с остановкой) действуют —
пометить их заменёнными было бы ложью. Выбрано: статусы не меняются,
связь — в «Связях» ADR-0051, как ADR-0046 обошлась с ADR-0019 (исполняет,
не заменяя).

### Р3. `strategy.md` не правится

Редакция заменяется только целиком. Её текст (стр. 147–149: «как ведутся
копии и восстановление, записывается элементом `deployment-decisions-cleanup`»)
остаётся верным: запись ADR-0051 и есть то, что записано, — что ведутся они
вне репозитория.

### Р4. Версия без изменения

Код меняется только в комментариях; поведение то же — это «документы
и оснастка».
