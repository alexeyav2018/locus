## Why

Учитель (замечание 08.10.2026, Locus 1.2.0) сказал: Подпись у Задачи
не нужна, нужен номер — простой сквозной. Номер уже есть: это идентификатор
Задачи, сквозной по всей библиотеке, и он уже показывается везде как
«Задача № N». Значит, просьба по существу — убрать Подпись: поле на форме,
которое учитель заполнять не будет, и колонку в схеме, которая без поля
превратится в поле без смысла.

## What Changes

- **BREAKING** Подпись (`caption`) уходит из Задачи целиком: поля нет
  на форме заведения и правки, Подпись не показывается ни на странице
  Задачи, ни в списке Темы, ни в результате поиска, ни в форме перестройки
  дерева, ни в Задании, ни на экране приёма Работ.
- **BREAKING** Миграция удаляет колонку `caption` таблицы `problem`
  вместе с уже введёнными значениями — необратимо, откатного скрипта нет
  ([ADR-0023](../../context/adr/0023-osnastka-sborki.md)). Перед выкладкой
  на стенд — копия базы.
- Номер не меняется: тот же идентификатор, сквозной, неизменный, с дырами
  после удаления (развилка 1(а) карточки, решено владельцем).
- Словарь, модель предметной области, сценарии и архитектура теряют
  упоминание Подписи.

Решение — новая запись журнала
[ADR-0050](../../context/adr/0050-zadacha-razlichaetsya-tolko-nomerom.md)
(«Предложено»); она заменяет
[ADR-0029](../../context/adr/0029-nomer-i-podpis-zadachi.md), у которой
статус — «Заменено».

**Граница общего и личного.** Общее: Задача библиотеки, ведёт
Администратор, читают все вошедшие. Фильтр по владельцу не появляется,
права не меняются. Личные экраны (Задание, приём Работ) только перестают
показывать Подпись библиотечной Задачи.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `problem-catalog`: требование «Задача различается номером и подписью»
  становится «Задача различается номером»; из чтения, списка Темы и правки
  уходит подпись.
- `library-search`: строка результата показывает номер без подписи,
  сценарий «Задача без подписи» снимается.
- `taxonomy`: форма снятия Темы перечисляет Задачи номером.
- `assignments`: Задание показывает Задачу с текущими номером и разметкой.
