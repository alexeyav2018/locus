# Proposal

## Why

Ученик, который перестал заниматься, не удаляется — на него ссылаются
Задания (и вскоре Работы и отметки), и удаление стёрло бы историю
([ADR-0035](../../context/adr/0035-udalenie-uchenika-i-gruppy.md)). Но он
остаётся в общем списке и в выборе адресата при выдаче: мешает найти
действующего Ученика и рискует получить Задание по ошибке. ADR-0035 прямо
отложил эту задачу до элемента `student-withdrawal`, заведённого не позже
`assignments`; `assignments` в архиве, срок наступил.

## What Changes

- У Ученика появляется состояние **выбыл / действует** (`withdrawn`),
  которое переключает сам Учитель — с возвратом обратно в любой момент.
- Список Учеников (`/students`) по умолчанию показывает только действующих;
  выбывшие доступны отдельным переключателем на той же странице, без
  отдельного экрана.
- Карточка выбывшего Ученика, его Задания, Работы и отметки Владения
  остаются доступны без изменений — выбытие ничего не прячет, кроме
  присутствия в списках выбора.
- Выбывший не предлагается при выдаче Задания одному Ученику
  (`/assignments/new`, адресат «Ученик»).
- Каскада на Группы нет: выбывший остаётся в составе Группы, в которой
  состоял. При выдаче Группе (Раздаче) он пропускается — Задание получают
  только действующие члены; если действующих членов не осталось, выдача
  отклоняется тем же сообщением, что для пустой Группы.
- Фильтры на чтение — сводка Заданий по Ученику, список Работ Ученика,
  экран Владения — по-прежнему принимают и выбывшего: они не выбор
  адресата, а обращение к уже существующей истории.

## Capabilities

### New Capabilities

(нет — расширяются существующие)

### Modified Capabilities

- `students-groups`: у Ученика появляется состояние выбытия, операция
  «пометить выбывшим» / «вернуть», список по умолчанию скрывает выбывших.
- `assignments`: выбывший Ученик не предлагается адресатом при выдаче
  одному Ученику; при выдаче Группе выбывшие члены пропускаются, а Группа
  без единого действующего члена отклоняется как пустая.

## Impact

- Код: `ru.locus.student.Student`, `StudentRepository`, `StudentService`,
  `StudentController` и шаблоны `student/list.html`, `student/student.html`
  (новое состояние и операция); `ru.locus.assignment.AssignmentController`
  и `AssignmentService` (источник списка Учеников для формы выдачи
  и правило пропуска при выдаче Группе); `GroupService.members` — не
  меняется (состав Группы не фильтруется).
- Схема: новая колонка у таблицы `student` (миграция Liquibase).
- Документы: новая запись в журнале решений (закрывает долг ADR-0035);
  запись термина «выбытие» в `glossary.md`; правка сводки в `CLAUDE.md`
  после архивации.
