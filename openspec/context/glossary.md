# Словарь предметной области

Единственный источник терминов. Слова отсюда используются **одинаково** в коде
(имена классов, полей, таблиц), в интерфейсе и в разговоре. Если для понятия
нужно новое слово — оно добавляется сюда, а не заводится по месту.

## Библиотека — общая на систему

| Термин | Значение |
| --- | --- |
| **Рубрикатор** | Дерево классификации задач произвольной глубины. Общий на всю систему, под Администратором. |
| **Раздел** | Внутренний узел рубрикатора. Несёт теоретические материалы; задач и отметок владения не несёт. |
| **Тема** | Лист рубрикатора. Несёт задачи и отметки владения. Единица измерения по оси рубрикатора. |
| **Задача** | Отдельная математическая задача: PDF с условием, PDF с решением и разметка. Существует независимо и переиспользуется. |
| **Метод** | Приём решения («разложение на множители», «теорема о пропорциональных отрезках»). Плоский общий словарь: метод сквозной для разных Тем. Единица измерения по оси методов. |
| **Характеристика** | Особенность задачи («наличие формул приведения», «двойной угол»). Используется только для поиска, в измерении владения не участвует. |
| **Часть** | Принадлежность задачи к первой или второй части ЕГЭ. В первой части ответ — целое число или конечная десятичная дробь, во второй — произвольное выражение. Используется только для поиска и подбора. |
| **Теоретический материал** | Текст, формулы или ссылки по теме. Крепится к любому узлу рубрикатора — и к Разделу, и к Теме. |

## Личный контур — у каждого учителя свой

| Термин | Значение |
| --- | --- |
| **Ученик** | Карточка школьника. Объект учёта, а не пользователь системы. Принадлежит ровно одному учителю. |
| **Группа** | Именованный список учеников одного учителя. Способ адресовать пачку заданий одним действием. |
| **Задание** | Набор задач, выданный **одному** ученику, со сроком сдачи. Переиспользуемых шаблонов заданий нет. |
| **Раздача** | Одно действие выдачи, породившее несколько Заданий (например, группе из двенадцати человек). Помнит общее происхождение, но не переиспользуется и повторно не выдаётся. |
| **Работа** | Присланное учеником решение задачи: обязательный скан или фотография, бинарный вердикт учителя и свободное текстовое примечание. |
| **Владение** | Отметка учителя о том, владеет ли ученик Методом в рамках Темы. Ставится на паре «Тема × Метод». Шкала: `неизвестно`, `не владеет`, `владеет неуверенно`, `владеет`. |

## Пользователи и роли

| Термин | Значение |
| --- | --- |
| **Пользователь** | Учётная запись входа. Имеет произвольный набор ролей; при входе получает объединённый функционал всех своих ролей. |
| **Роль** | Набор прав, а не режим работы. Активная роль не выбирается. |
| **Администратор** | Роль, владеющая общим: рубрикатор, словари, задачи, теория. Единственная, кому доступны разрушительные операции над библиотекой. |
| **Учитель** | Роль, владеющая личным: ученики, группы, задания, работы, отметки владения. Библиотеку читает и использует. |

## Слова, вышедшие из употребления

Термины из чернового словаря, которые больше не используются. Оставлены здесь,
чтобы их не завели заново.

| Было | Стало | Почему |
| --- | --- | --- |
| **Выдача** | **Задание** | После отказа от шаблонов ([ADR-0016](adr/0016-zadaniya-bez-shablonov.md)) «задание» и «выдача» схлопнулись в одну сущность; держать два слова незачем. |
| **Тип**, **подтип** | **Раздел**, **Тема** | Двухуровневая структура заменена деревом ([ADR-0006](adr/0006-rubrikator-derevo.md)). Кроме того, «тип задания» путался с «Заданием» — тем, что получает ученик. |
| **Ответ** | **Работа** | Ученик ничего не присылает в систему; в математике «ответ» — это число, и путаница была бы неизбежной. |
