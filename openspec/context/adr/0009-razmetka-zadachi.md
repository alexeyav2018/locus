# ADR-0009. Разметка задачи: Темы, Методы (обязательны), Характеристики, Часть

## Контекст

Раз текста задачи система не знает ([ADR-0008](0008-zadacha-dva-pdf.md)),
разметка — единственный вход в базу. Учитель описал четыре разных измерения:
принадлежность разделам математики, часть ЕГЭ, характеристические особенности
задачи и методы её решения. Требовалось понять, какие из них обязательны и
какие участвуют в измерении владения.

## Решение

Разметка задачи:

| Измерение | Кратность | Роль |
| --- | --- | --- |
| Тема | 1..n, только листья | поиск и ось измерения |
| Метод | **1..n, обязателен** | поиск и ось измерения |
| Характеристика | 0..n | только поиск |
| Часть ЕГЭ | ровно одна (1 или 2) | только поиск и подбор |

## Причины

- Минимум один Метод обязателен, потому что отметка владения живёт на паре
  «Тема × Метод» ([ADR-0011](0011-otmetka-na-pare.md)): задача без методов не
  порождает ни одной ячейки и остаётся «немой» для статистики. Обнаружилось бы
  это через полгода, по пустым ячейкам.
- Характеристики в измерении не участвуют: учитель ведёт статистику по типам
  задач и методам, про характеристики речи не было. Они — уточняющий фильтр
  поиска.
- Часть ЕГЭ после отказа от автопроверки
  ([ADR-0014](0014-proverka-bez-avtomatiki.md)) перестала влиять на поведение
  системы и осталась атрибутом для подбора («дай задачи первой части»).

## Отвергнутые альтернативы

### Методы необязательны (0..n)

Исходное предположение; отклонено по причине выше.

### Характеристики как третья ось измерения владения

Не рассматривалась всерьёз: умножила бы число ячеек, не добавив того, чем
учитель пользуется.

## Последствия

- Форма разметки нетривиальна: выбор нескольких узлов из дерева плюс несколько
  методов из общего словаря. Чтобы список методов не был свалкой, показываются
  те, что уже встречались в этой Теме, с возможностью раскрыть все
  ([ADR-0010](0010-slovar-metodov-ploskij.md)).
- Качество разметки определяет находимость задачи целиком; ошибка в разметке
  равносильна потере задачи.
- Ячейки владения порождаются фактическим употреблением пар в разметке,
  а не перемножением словарей.
