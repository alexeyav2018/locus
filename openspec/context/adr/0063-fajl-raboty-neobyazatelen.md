# ADR-0063. Файл Работы необязателен, основание отметки — суждение учителя

## Контекст

[ADR-0015](0015-skany-rabot-hranyatsya.md) сделал скан или фотографию
решения обязательной частью Работы. Решение опиралось на две предпосылки:

1. **«Работы и так приходят фотографиями»** — значит, хранение снимка
   не новый труд, а перенос существующего из переписки.
2. **Обоснование отметки — образ работы**: отметки Владения хранятся без
   истории ([ADR-0012](0012-shkala-vladeniya.md)), и без снимка обосновать
   их нечем.

Практика опровергла первую. Просьба владельца 09.11.2026: файла у решения
нет по двум причинам. Решение видели вживую — тетрадь на занятии, устный
ответ у доски, — и фотографии не существует вовсе. Либо фотография есть,
но перенос её в Локус дорог: найти в переписке, сохранить, загрузить
с телефона ради одной Задачи. В обоих случаях учитель сейчас либо
не записывает вердикт и отметку совсем, либо прикладывает посторонний
снимок, чтобы пройти проверку «нужен хотя бы один файл», — то есть
обязательность файла порождает ровно ту запись без основания, от которой
она должна была защищать.

Вторая предпосылка опровергнута прецедентом: [ADR-0061](0061-razminka-svoya-zapis-vtoroe-osnovanie-otmetki.md)
уже сделал основанием отметки Разминку, у которой файлов нет совсем, —
обоснованием там служит суждение учителя, видевшего решение. Отметку
ставит только человек ([ADR-0011](0011-otmetka-na-pare.md)); снимок её
подкрепляет, но не создаёт.

Разминкой этот случай не закрывается: решение принадлежит Задаче
выданного Задания, Работа по ней снимает «не сдано» и держит Задание
от удаления, а Разминка — отдельная запись без срока и без Задания.

## Решение

Файл у Работы **необязателен**. Работа принимается с файлами либо без
них; дата получения, вердикт, примечание и отметки Владения — как прежде.

- **Работа без файла — полноценная Работа.** Она снимает «не сдано»
  с Задания, держит Задание и Ученика от удаления и считается в справке
  у ячейки Владения «Работы: N из M» наравне с Работой с файлами:
  основание отметки — суждение учителя, файл — лишь его подкрепление.
- **Файлы приходят позже** тем же дополнением файлов к принятой Работе,
  что и повторная присылка ([ADR-0038](0038-rabota-odna-na-paru-i-udalyaetsya-svobodno.md)).
- **Последний файл по-прежнему не удаляется.** У Работы, у которой файлы
  есть, хотя бы один остаётся: удалить снимок, оставив запись, — значит
  выдать прежнее основание за отсутствующее. Ошибочную загрузку
  исправляют, как и прежде, удалением Работы целиком и приёмом заново.
  Тем самым следствие ADR-0038 «Работа без файла не существует» сужается
  до «у Работы с файлами последний файл не удаляется»; остальное
  в ADR-0038 не меняется.
- **Отсутствие файла видно**: у Работы без файла пометка «без файла»
  и действие «Приложить файлы» — на экране приёма и в списке Работ
  Ученика. Пометка — состояние данных (файлов нет), а не хранимый флаг.

Остальные следствия ADR-0015 остаются в силе: файлы Работы — персональные
данные детей, отдаются только по временной ссылке, снимок пережимается,
загрузка рассчитана на телефон, Работа привязана к Задаче Задания.

## Причины

- Обязательный файл в практике не защищает основание отметки, а подделывает
  его: учитель прикладывает посторонний снимок, и запись выглядит
  обоснованной, хотя не обоснована ничем, кроме его суждения. Честнее
  хранить суждение без файла и показывать это.
- Основание без файла в системе уже есть и работает — Разминка (ADR-0061).
  Равная справка по Работам с файлом и без не вводит нового правила, а
  распространяет уже принятое на Задание.
- Работа без файла — отсутствие строк файлов, а не новый вид записи:
  схема, изоляция по владельцу и вопросы `AssignmentWork` и `StudentUsage`
  не меняются.

## Отвергнутые альтернативы

### Оставить файл обязательным (ADR-0015 как есть)

Отклонена: обе предпосылки ADR-0015 не подтвердились — фотографии нет
у решения, увиденного вживую, а перенос существующей дорог; основание
отметки без файла уже принято Разминкой.

### Обязательное примечание при приёме без файла

Учитель словами объясняет, на чём основан вердикт. Отклонено владельцем
09.11.2026: это тот же лишний труд, что и перенос снимка, только другим
путём, и формальная строка «видел на занятии» ничего не добавляет
к суждению.

### Работа без файла не основание отметки

Вердикт без файла ставится, а отметки по такой Работе запрещены либо
не считаются в справке. Отклонено владельцем 09.11.2026: суждение учителя,
видевшего решение, — то же основание, что у Разминки; запрет вернул бы
обходной путь с посторонним снимком.

### Последний файл удаляется, Работа остаётся без файла

Отклонено владельцем 09.11.2026: файл, однажды приложенный как
основание, не исчезает молча; ошибочная загрузка исправляется удалением
Работы целиком — как и прежде.

### Без пометки «без файла»

Работа без файла выглядит как любая другая. Отклонено владельцем
09.11.2026: учитель, возвращающийся к прошлым работам, должен видеть,
где снимка нет и где его можно приложить.

## Последствия

- Поток файлов в хранилище растёт медленнее, чем предполагал ADR-0015:
  часть Работ приходит без них.
- Справка «Работы: N из M» больше не означает «N снимков, на которые
  можно посмотреть»: часть Работ может быть без файла. Пометка «без
  файла» в списке Работ Ученика делает это видимым.
- Словарь (термин «Работа»), модель (раздел об удалении Работы), сценарий
  С5 и спека `submission-review` правятся вслед.
- Обоснование [ADR-0012](0012-shkala-vladeniya.md) «Работы хранятся
  обязательно, поэтому обоснование не теряется» ослабевает: хронологию
  по-прежнему восстанавливают по Работам Ученика, но часть из них —
  суждения без снимка. Отказ от истории отметок это не отменяет.
