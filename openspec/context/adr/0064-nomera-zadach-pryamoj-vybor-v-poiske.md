# ADR-0064. Номера Задач в поиске — прямой выбор, отменяющий условия разметки

## Контекст

Поиск по библиотеке ([ADR-0031](0031-uslovija-poiska-po-biblioteke.md))
отбирает Задачи только по разметке: узел рубрикатора с поддеревом, Методы,
Характеристики, Часть; разные условия соединяются по «и» всегда.

Отзыв владельца 09.11.2026: у учителя часто уже есть список номеров —
«3, 5, 7, 12» с бумаги, из прошлого варианта, из записи в тетради. Номер —
единственное, чем Задача названа человеку
([ADR-0050](0050-zadacha-razlichaetsya-tolko-nomerom.md)). Собрать эти
Задачи для выдачи или Разминки сейчас можно, лишь листая библиотеку
или открывая каждую по номеру и запоминая.

Номера — не измерение разметки, а имя Задачи. Встаёт вопрос, как они
соотносятся с условиями разметки: ещё одно условие по «и», как велит
ADR-0031 для всех условий, или нечто иное. Решено владельцем вопросами
09.11.2026.

## Решение

**Номера Задач — прямой выбор, а не условие отбора.** Заданные номера
отменяют все условия разметки: показываются ровно Задачи с этими номерами,
что бы ни стояло в узле, Методах, Характеристиках и Части.

- На экране поиска у номеров **своя форма** — блок «Номера Задач» над
  условиями разметки, со своей кнопкой. Каждая форма отправляет только
  свои поля; на странице результата заполнена та, которой искали. Если
  в адресе есть и номера, и условия разметки, действуют только номера.
- **Поле номеров** — числа, разделённые запятыми, пробелами, точками
  с запятой и переводами строк в любой смеси. Диапазонов («3-7») нет.
  Повторённый номер — один номер. Посторонний кусок — отказ с его
  названием, результата нет.
- **Номер, которого нет в библиотеке, не отменяет найденного:** найденные
  показываются, пропавшие называются строкой «Нет в библиотеке: …».
- Тем же правилам следует инструмент Помощника `find_problems`.

**Остаётся в силе из ADR-0031** — для поиска по разметке:

- условия по Методу и по Характеристике берут любое число значений, и для
  каждого учитель выбирает способ соединения — **все сразу** или **любое
  из**; умолчание — «любое из»; режимы у двух условий независимы;
- узел рубрикатора и Часть берут не более одного значения;
- разные условия разметки соединяются по «и» всегда, переключателя нет;
- пустой набор значений — отсутствие условия, а не условие из пустого
  набора;
- выдача не усекается: показываются все найденные и их число,
  постраничности нет;
- по Подписи не ищется (Подпись удалена
  [ADR-0050](0050-zadacha-razlichaetsya-tolko-nomerom.md)).

## Причины

- **Номера с условием по «и» тихо теряют Задачи.** Учитель, вернувшийся
  к поиску с выбранным раньше узлом, ввёл бы пять номеров и увидел бы три —
  те, что случайно лежат в том узле. Правдоподобный результат, из которого
  не видно, что две Задачи отсеяны не тем условием. Прямой выбор такого
  исхода не допускает: список номеров есть ответ.
- **Своя форма делает режим видимым.** Подсказка «прочие условия
  не применены» при одной общей форме требовала бы от учителя прочесть
  и понять её; две формы с двумя кнопками показывают, каким способом
  искали, самим видом страницы.
- **Ненайденный номер — частая опечатка, а не повод отказать во всём.**
  Отказ целиком заставил бы найти и убрать номер, прежде чем увидеть
  остальные; называние пропавших сохраняет и результат, и знание о потере.

## Отвергнутые альтернативы

### Номера как ещё одно условие по «и»

Единообразно с ADR-0031 и не требует новой записи. Отклонено владельцем:
вместе с забытым условием разметки теряет Задачи молча — см. «Причины».

### Отказ целиком при ненайденном номере

Строже и проще в показе. Отклонено: опечатка в одном номере прятала бы
остальные, а исправлять её пришлось бы вслепую.

### Одна форма с подсказкой «прочие условия не применены»

Меньше разметки на странице. Отклонено: режим держался бы на прочтении
подсказки, а не на виде формы.

### Вывод в порядке ввода

Порядок, в котором учитель продиктовал номера, кажется осмысленным.
Отклонено владельцем вместе с выбором общего порядка: результат поиска
любым способом идёт по убыванию номера (спецификация `library-search`),
и особый порядок у одного способа был бы вторым правилом показа.

### Диапазоны «3-7»

Удобны для подряд идущих номеров. Не вошли: у листа бумаги номера редко
идут подряд, а дефис в поле стал бы отказом-подсказкой, если понадобится.
Вернуться — когда учитель попросит.

## Последствия

- Экран поиска получает вторую форму; `ProblemFilter` не меняется —
  номера идут мимо него отдельным путём сервиса.
- Отбор по номерам — второй вход в поиск рядом с отбором по разметке;
  подбор под пробел (`mastery-views`) по-прежнему передаёт только
  разметку.
- Ответ `find_problems` называет ненайденные номера.
- ADR-0031 заменяется этой записью целиком; её доводы о способах
  соединения остаются верными и перечитываются там.
