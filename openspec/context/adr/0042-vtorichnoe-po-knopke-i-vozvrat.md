# ADR-0042. Вторичное — по кнопке на той же странице; контекстный возврат параметром from; просмотр файлов внутри страницы

## Контекст

После [ADR-0041](0041-edinaya-sistema-oformleniya.md) экраны выглядят единообразно,
но показывают всё сразу, а выйти из тупика (форма без «Отмены», ошибка без шапки,
файл в чужой вкладке, «назад» без условий поиска) можно только средствами
браузера. Владелец потребовал: только полезное на странице, остальное по кнопке
на той же странице, навигация кнопками.

## Решение

- Вторичное прячется под `<details>` на той же странице. Блоки одного экрана
  исключают друг друга атрибутом `name`. Раскрытие при отказе сервиса
  определяется адресом отклонённого действия, который знает `ShellAdvice`, —
  контроллеры не меняются.
- Возврат — параметром `from` со внутренним адресом; принимается только
  проверенное значение (`ReturnTo`), прочее игнорируется.
- Файлы открываются на странице просмотра внутри системы: изображение —
  картинкой, PDF — встроенным просмотром с запасной ссылкой. Рамка от
  собственного источника разрешается (`X-Frame-Options: SAMEORIGIN`
  вместо `DENY`).
- Собственные страницы ошибок и «Выйти» в шапке.

## Причины

- Задача решается на стандартных элементах HTML без новых зависимостей;
  страницы остаются работоспособными без JavaScript.
- Раскрытие по адресу отклонённого действия не требует правки двадцати девяти
  мест в контроллерах.
- `from` в адресе переживает перезагрузку и работает со ссылками; хранение
  «последнего списка» в сеансе ломалось бы при двух вкладках.

## Отвергнутые альтернативы

### htmx и подгрузка блоков с сервера

Отклонена сейчас: нужны отдельные адреса-фрагменты, новая зависимость и
пересмотр запрета скриптов в шаблонах, а выигрыш — только если вторичное станет
дорогим по данным. Вернуться стоит, когда это случится.

### Возврат через `history.back()`

Отклонена: это те же средства браузера под видом кнопки, и она бессильна после
отказа формы или открытия по прямой ссылке.

### Модальные окна для форм

Отклонена: владелец описал раскрытие на той же странице; модальное окно на
телефоне перекрывает контекст, и для него нужен JavaScript.

## Последствия

- Встроенный просмотр PDF на телефонах ненадёжен; запасная кнопка открывает
  файл как раньше. Просмотр изображений от этого не зависит.
- Рамка для своего источника ослабляет защиту от встраивания только для
  страниц самого приложения.
- После действия переход идёт на раздел по умолчанию, а не обратно по `from`:
  контекст сохраняется до действия, а не через него.
