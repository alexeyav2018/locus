# ADR-0041. Единая система оформления — общий каркас, свой CSS и точечный JavaScript без фреймворков

## Контекст

Экраны строились по одному, каждый со своим блоком `<style>` или вовсе без
него; общей навигации не было. Владелец признал интерфейс неудобным
и попросил новый дизайн при сохранении архитектуры. Задача 4.2 рубрикатора
запрещала любой JavaScript в шаблонах (`noTemplateCarriesAScript`), хотя
ADR-0020 прямо допускал «точечные вставки JavaScript внутри серверных
страниц».

## Решение

- Оформление — один файл `static/css/locus.css` с токенами, светлой и тёмной
  темами; страницы собираются из общего каркаса `templates/fragments/shell.html`
  (подключение стилей и шапка с разделами). Данные шапки даёт `ShellAdvice`.
- Своих стилей у шаблонов нет.
- JavaScript — один файл `static/js/locus.js`, без библиотек и сборки;
  он только убирает неудобство (подтверждение необратимого, выбор нескольких
  значений без Ctrl, защита от двойной отправки). Без него каждая страница
  работает. Встроенных скриптов и обработчиков в разметке нет.
- Граница общего и личного показана цветом и меткой на каждом экране.
- Концепция и правила для новых экранов — `ux-concept.md`.

## Причины

- Единообразие снижает нагрузку на учителя и стоимость нового экрана.
- Решение укладывается в ADR-0020: отдельного фронтенда нет, скрипт точечный.
- Системные шрифты и отсутствие внешних подключений — работает без сети
  и не утекает адресами в сторонние сервисы.

## Отвергнутые альтернативы

### CSS-фреймворк (Bootstrap, Tailwind)

Отклонена: даёт внешнюю зависимость и сборку ради набора компонентов, которого
хватает в двухстах строках собственного CSS. Вернуться стоит, если экранов
станет настолько много, что собственная система не справляется.

### htmx или SPA-фронтенд

Отклонена сейчас: страницы с перезагрузкой справляются, а компетенции для
отдельного фронтенда по-прежнему нет (ADR-0020).

## Последствия

- Тест `noTemplateCarriesAScript` пересмотрен: в шаблонах запрещены встроенные
  скрипты и обработчики, допущено лишь подключение `/js/locus.js` из каркаса.
- Шапка не содержит форм; выход — на странице смены пароля и на главной.
- Пункты шапки по ролям — удобство, а не права (как ссылки на главной).
- Главная учителя запрашивает у сервисов несданные Задания и число Учеников.
