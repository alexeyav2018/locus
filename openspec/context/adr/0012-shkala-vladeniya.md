# ADR-0012. Шкала владения из четырёх значений; хранится только текущее

## Контекст

Отметка ставится человеком ([ADR-0011](0011-otmetka-na-pare.md)) и выборочно,
поэтому большая часть ячеек в любой момент не заполнена. Требовалось решить,
какие значения различает шкала и что происходит со старым значением при новой
простановке.

## Решение

Шкала из четырёх значений: `неизвестно`, `не владеет`, `владеет неуверенно`,
`владеет`. Значение по умолчанию для любой новой пары — `неизвестно`.

Хранится только **текущее** значение. Новая простановка затирает прежнее;
история изменений не ведётся.

## Причины

- Состояние `неизвестно` необходимо и не сводится к `не владеет`: пустая ячейка
  у нового ученика означает «мы туда ещё не ходили». Без этого различия у любого
  новичка вся картина красная, и по ней нельзя подобрать, что дать дальше.
- `владеет неуверенно` запрошено учителем: бинарной шкалы для реального
  суждения о школьнике не хватает.
- Отказ от истории — решение заказчика: если понадобится хронология, учитель
  поднимет Работы ученика и разберётся. Работы хранятся обязательно
  ([ADR-0015](0015-skany-rabot-hranyatsya.md)), поэтому обоснование не теряется.

## Отвергнутые альтернативы

### Три значения без «владеет неуверенно»

Отклонена заказчиком как недостаточно выразительная.

### Хранить историю изменений отметки (запись с датой вместо перезаписи)

Рассматривалась и рекомендовалась: стоит немного, даёт годовую динамику
запросом вместо ручного перебора работ. Отклонена заказчиком в пользу простоты.
Добавить позже несложно — новые значения начнут копиться, но прошлые
не восстановятся. Элемент бэклога `mastery-history`.

## Последствия

- Различать `неизвестно` и `не владеет` нужно везде: в подборе задач, в
  распределениях, в цвете ячейки. Смешение этих двух состояний — типовая ошибка.
- Одна неудачная работа может обнулить накопленное впечатление: если учитель
  поставит `не владеет`, три месяца наблюдений исчезнут. Это осознанная цена;
  смягчается тем, что рядом с ячейкой показывается справка по истории решений.
- На вопрос «как менялась отметка за год» система не отвечает; ответ собирается
  глазами по Работам.
