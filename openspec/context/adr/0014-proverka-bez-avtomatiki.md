# ADR-0014. Проверка без автоматики: бинарный вердикт и текстовое примечание

## Контекст

Деление задач на части ЕГЭ выглядело как приглашение к автоматической проверке:
в первой части ответ — целое число или конечная десятичная дробь, то есть ровно
то, что машина умеет сверять. Требовалось решить, вводить ли автосверку и в
каком виде фиксируется результат проверки. Нужна ли автоматическая проверка
ответов, значилось открытым вопросом в `CLAUDE.md`.

## Решение

Автоматической проверки нет ни для одной части. По каждой задаче задания
учитель ставит **бинарный вердикт** (верно / неверно) и может добавить
свободное текстовое примечание.

## Причины

- Ученик не пользователь системы ([ADR-0003](0003-sistema-instrument-uchitelya.md)):
  он не вводит ответ, а присылает решение изображением. Сверять нечего.
- Даже при вводе ответа выигрыш был бы мал: верный ответ не означает владения
  методом (угадал, подобрал, решил иначе), а отметки владения всё равно ставит
  человек, глядя на работу ([ADR-0011](0011-otmetka-na-pare.md)).
- Единая механика для обеих частей проще: часть ЕГЭ перестаёт переключать
  поведение системы.

## Отвергнутые альтернативы

### Автосверка ответа первой части как подсказка учителю

Рекомендовалась при обсуждении: система показывает «сошлось / не сошлось»,
учитель открывает только спорные. Отклонена заказчиком вместе с самим вводом
ответа учеником.

### Трёхзначный вердикт с «решено частично»

Предлагалась для второй части, где работа бывает верна наполовину. Отклонена
заказчиком в пользу бинарного вердикта плюс примечания: словами учитель опишет
частичность точнее любой градации.

## Последствия

- Поле «эталонный ответ» у задачи не нужно: оно требовалось только автосверке
  ([ADR-0008](0008-zadacha-dva-pdf.md)).
- Часть ЕГЭ остаётся атрибутом для поиска и подбора, не влияя на поведение
  ([ADR-0009](0009-razmetka-zadachi.md)).
- Закрыт открытый вопрос `CLAUDE.md` об автоматической проверке.
- Примечание — свободный текст, поиском по нему система не занимается.
