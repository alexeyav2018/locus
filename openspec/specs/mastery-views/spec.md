## Purpose

Вид на Владение Ученика: распределения отметок по четырём статусам
по Теме, Разделу и Методу, перечень пробелов и переход из пробела
в подбор Задач — то, ради чего ведётся разметка библиотеки и ставятся
отметки. Только чтение: отметки ставятся на экране приёма.

## Requirements

### Requirement: Экран Владения Ученика — только чтение

Система SHALL показывать Учителю экран Владения его Ученика
(С6 [scenarios.md](../../context/scenarios.md)): распределения
по Теме, по Разделу и по Методу и перечень пробелов. Экран MUST NOT
содержать ни одной формы простановки или правки отметок: отметка ставится
только на экране приёма, по принятой Работе, точечно
([ADR-0011](../../context/adr/0011-otmetka-na-pare.md)). Карточка
Ученика SHALL вести на этот экран.

#### Scenario: Переход с карточки Ученика

- **WHEN** Учитель открывает карточку своего Ученика
- **THEN** на ней есть ссылка на экран Владения этого Ученика

#### Scenario: Экран без форм

- **WHEN** Учитель открывает экран Владения Ученика, у которого есть
  отметки
- **THEN** отметки показаны числами в распределениях и строками в перечне
  пробелов
- **AND** ни одной ячейки со средством смены значения на экране нет

### Requirement: Владение по Теме, Разделу и Методу — распределения по четырём статусам

Каждый срез Владения система SHALL показывать как **распределение
по четырём статусам** — сколько ячеек `владеет`, `владеет неуверенно`,
`не владеет` и `неизвестно`
([ADR-0013](../../context/adr/0013-agregaciya-raspredelenie.md),
инвариант 5 [domain-model.md](../../context/domain-model.md)):

- **по Теме** — по её ячейкам «Тема × Метод»;
- **по Разделу** — по всем ячейкам его поддерева; показывается всё дерево,
  у каждого узла — своё распределение;
- **по Методу** — по всем Темам, где Метод встречается.

Единого вычисленного «значения владения» для Темы, Раздела или Метода
MUST NOT существовать ни на экране, ни в коде — только четыре числа.
`Неизвестно` показывается как обычное число наравне с остальными:
это норма, а не тревога. `Неизвестно` и `не владеет` MUST различаться
([ADR-0012](../../context/adr/0012-shkala-vladeniya.md)).

#### Scenario: Распределение по Теме

- **WHEN** у Темы четыре ячейки, и Учитель поставил Ученику на одной
  «владеет», на одной «не владеет», а двух не касался
- **THEN** у Темы показано: владеет 1, владеет неуверенно 0,
  не владеет 1, неизвестно 2

#### Scenario: Распределение по Разделу складывается из поддерева

- **WHEN** у Раздела две Темы, на первой Ученику поставлено «владеет»
  и «не владеет», на второй — «владеет неуверенно», а прочих ячеек в них
  нет
- **THEN** у Раздела показано: владеет 1, владеет неуверенно 1,
  не владеет 1, неизвестно 0

#### Scenario: Распределение по Методу сквозь Темы

- **WHEN** Метод встречается в Задачах двух Тем, и Ученику на первой паре
  поставлено «владеет», а на второй — «не владеет»
- **THEN** у Метода показано: владеет 1, владеет неуверенно 0,
  не владеет 1, неизвестно 0

#### Scenario: Семь и один против одного и семи

- **WHEN** у одного Ученика на Теме из восьми ячеек семь «владеет»
  и одно «не владеет», а у другого — одно «владеет» и семь «не владеет»
- **THEN** распределения показаны разными: «владеет 7, не владеет 1»
  и «владеет 1, не владеет 7»
- **AND** никакого сведённого к одному слову итога у Темы нет

### Requirement: Ячейки порождены разметкой Задач

Ячейками Темы система SHALL считать пары «Тема × Метод», для которых
существует Задача, размеченная и этой Темой, и этим Методом
(инвариант 4 [domain-model.md](../../context/domain-model.md)),
а также пары, на которых у этого Ученика стоит отметка. Ячейка без
отметки считается как `неизвестно`. Декартово произведение Тем и Методов
ячейками MUST NOT считаться. Узел без единой ячейки в поддереве
показывается без распределения.

#### Scenario: Ячейка без Задачи не считается

- **WHEN** в словаре десять Методов, а Задачи Темы размечены только двумя
  из них
- **THEN** у Темы две ячейки, и «неизвестно» у Ученика без отметок равно 2

#### Scenario: Узел без ячеек

- **WHEN** в поддереве Раздела нет ни одной Задачи
- **THEN** у Раздела распределение не показано, а показано, что ячеек нет

### Requirement: Перечень пробелов ведёт в поиск Задач

Система SHALL показывать перечень пробелов Ученика — ячейки со статусом
`не владеет`, напрямую, без агрегатов
([ADR-0013](../../context/adr/0013-agregaciya-raspredelenie.md)),
каждую с полным путём Темы и именем Метода. Из каждого пробела SHALL
открываться поиск по библиотеке с условиями «узел — эта Тема, Метод — этот
Метод» (С4 «Подбор по пробелам»
[scenarios.md](../../context/scenarios.md)) — тот же поиск, что
и по фильтру, а не отдельный. Ячейки со статусом `неизвестно` пробелами
MUST NOT считаться.

#### Scenario: Пробел открывает поиск по паре

- **WHEN** Ученику на паре «Тема T × Метод M» поставлено «не владеет»
- **THEN** в перечне пробелов есть строка с путём T и именем M
- **AND** её ссылка открывает поиск по библиотеке с узлом T и Методом M,
  и в результатах — Задачи, размеченные и T, и M

#### Scenario: Неизвестное — не пробел

- **WHEN** у Ученика нет ни одной отметки
- **THEN** перечень пробелов пуст, хотя ячеек с «неизвестно» много

### Requirement: Учитель видит только своего Ученика

Экран Владения система SHALL показывать только владельцу Ученика; чужой
Ученик MUST быть неотличим от несуществующего. Владелец назначается
по вошедшему и MUST NOT приниматься из запроса. Распределения
и пробелы считаются только по отметкам владельца; дерево и Методы
показываются из общей библиотеки без фильтра по владельцу
([ADR-0027](../../context/adr/0027-mehanizm-granicy-obshchego-i-lichnogo.md)).
Экран доступен только роли Учителя.

#### Scenario: Чужой Ученик

- **WHEN** Учитель Б открывает экран Владения Ученика Учителя А по прямому
  адресу
- **THEN** ответ такой же, как для несуществующего Ученика

#### Scenario: Отметки другого Учителя не считаются

- **WHEN** Учитель А поставил своему Ученику «не владеет» на паре, а Учитель
  Б открывает экран своего Ученика
- **THEN** в распределениях Учителя Б эта отметка не учтена, а в перечне
  пробелов её нет

#### Scenario: Администратор

- **WHEN** Администратор открывает экран Владения по прямому адресу
- **THEN** доступ отклонён
