Текст

Markdown; формулы LaTeX — строчные между $…$, выключные между $$…$$; знак доллара — \$. Сомнительное Помощник помечает ⟦…⟧: пометки в Задачу не попадают, их можно оставить.

Улики

Куски листа, с которых распознан текст. Строки можно двигать, убирать и обводить заново; добавить файл можно при работающем скрипте.

Отмена

«Сохранить как Задачу» заводит Задачу с текстом, Улики — из строк. «Взять снимок как есть» — Задачу без текста: PDF условия и решения собираются из тех же строк. Обе сначала сохраняют введённое.
